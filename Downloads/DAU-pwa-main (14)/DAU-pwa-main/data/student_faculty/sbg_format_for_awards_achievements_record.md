# Format for Awards & Achievements Record

> Reformatted (2026-08-09): the original had "Details of the Award" repeated as a field label 6 times with different sub-fields crammed together, and empty placeholder headers for blank template rows. Cleaned up below — this is a blank fillable template; content unchanged.

Awards and Achievements (Students) for Cultural & Other Events

Details of Awards Won by DAU students in various competitions, such as Cultural and Other events.

*Note: Scanned Copy of Proof should be submitted with this form*

## Record Template (fields per entry)

- **Sr. No.**
- **Name of the Student**
- **Student ID**
- **Program**
- **Details of the Award:**
  - Name of the Event
  - Type (Individual/Team)
  - Organised By (University/Body)
  - Date (DD-MM-YY)
  - Venue
  - Prize Won (I/II/Other, etc.)
- **Level of the Event:** (Inter College/State/National/International)
- **Nature of the Award:** (Cash/Certificate/Medal, etc.)
- **Online (Y/N)**

*(This is a blank fillable template — the source document had 5 empty record slots for entries to be filled in.)*
