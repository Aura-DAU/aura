## Course Description
This course on UX Research and Design for Mobile Application offers an in-depth study of user experience (UX) ideas and practical design methodologies specifically for mobile applications. During a 14-week period, students will acquire the ability to comprehend and prioritize user requirements, utilizing these insights to develop intuitive, user-centric mobile application designs.

The course commences with fundamental UX principles and explores the comprehensive mobile UX process, encompassing user research techniques, path mapping, competitive analysis, and task analysis. Students have practical experience in organizing information, creating wireframes, and developing interactive prototypes. Emphasis is placed on visual design concepts, accessibility, and usability testing, allowing students to develop apps that are aesthetically pleasing and highly functional.

Practical sessions encourage student engagement with authentic design challenges, cultivating competencies in user interviews, persona creation, A/B testing, and iterative design processes. This course combines theoretical knowledge with practical experience, providing students with the essential skills to succeed in mobile UX research and design, preparing them for careers in a predominantly mobile-first environment.

## Course Outcomes (COs)
After successful completion of this course, students will be able to:

| CO | IE418 Description |
|---|---|
| CO1 | Conduct Comprehensive UX Research for mobile applications, using a variety of methods to identify user needs and inform design decisions. |
| CO2 | Create User Personas and Journey Maps that reflect insights from research and define a target audience and their interaction with the app. |
| CO3 | Design Effective Information Architecture and Wireframes that structure app content logically, aligned with users' mental models. |
| CO4 | Build Interactive Prototypes for mobile applications, showcasing fundamental design elements and navigation flows. |
| CO5 | Execute Usability Tests and design adjustments to improve user satisfaction, usability, and accessibility. |
| CO6 | Collaborate in a UX Workflow by preparing design specifications, style guides, and providing clear handoffs for developers, simulating professional UX design environments. |

## Course Structure

| IE418 Unit | Topic | No. of Lectures |
|---|---|---|
| Introduction to UX Research & Design | What is UX and why it matters; Overview of UX research methods; Introduction to the mobile-first design approach. | L-1, P-1 |
| Understanding Users & Context of Use | User-centered design process; Understanding mobile app users and their context; Conducting user interviews and surveys. | L-1, P-1 |
| User Journey Mapping & Task Analysis | Introduction to user journey mapping; Identifying user tasks and workflows; Task analysis for mobile applications. | L-1, P-1 |
| Competitive Analysis & Mobile Design Trends | Performing competitive UX analysis; Mobile design patterns and trends; Analysis of successful mobile apps. | L-1, P-1 |
| Information Architecture for Mobile | Principles of information architecture; Structuring mobile app content; Card sorting techniques. | L-2, P-2 |
| Wireframing & Visual Design Principles | Low-fidelity and high-fidelity wireframing techniques; Tools for wireframing; Mobile design principles; Designing for small screens. | L-2, P-2 |
| Accessibility in Mobile Design | Principles of accessible design for mobile apps; Guidelines for designing for disabilities; Implementing accessibility in mobile UX design. | L-1, P-1 |
| UX Audit & Design handoff | Audit your prototype; Design specifications and Style guides. | L-1, P-1 |
| Interaction Design, Prototyping & Usability Testing | Introduction to interaction design; Prototyping tools; Creating interactive prototypes; Usability testing. | L-2, P-2 |
| Final Project Presentations & Feedback | Presentation of final mobile app design; Class critique and feedback on presentations; Finalize project deliverables. | L-2, P-2 |

## Program Structure Context
This course is offered as an Open Elective for B.Tech. students (typically in Semester 6) and as an Elective for other programs like M.Tech., M.Sc., and M.Des. It provides specialized, practical knowledge in mobile application design and user experience, complementing core engineering and development skills.

---

## Additional Notes
- **Course Objectives:** Introduce foundational UX principles, equip students with research skills, instruct on mobile application design techniques (wireframing, prototyping), encourage usability and accessibility, and foster analytical skills in UX measurement.
- **Project Work:** Students will be expected to design a fully interactive mobile app prototype based on the research conducted throughout the course. Deliverables include user personas, journey maps, wireframes, and an interactive prototype tested for usability.
