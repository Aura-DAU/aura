## Course Description

Core course for MDes (CD) Semester 3. This is an advanced specialised course in design and is aimed to integrate the inputs in the previous courses into a 'multimedia' matrix, specifically focusing on understanding the online interactive web driven ecosystem.

Through discussing various examples students would be introduced to Web Concepts and Design — the basic technical requirements and production processes needed for basic website development and construction. Topics include site design, image processing, visual web editors, HTML and layout, interface design and basic behaviours, along with hands-on experience connecting to a network. As a class project, students set up a site that becomes a context to apply what they learn and present the work to others.

Through this process students learn to combine various software tools used to create multimedia content, understanding the advantages/disadvantages of specific software, their compatibility with each other, cross-platform applications, and the optimum manner to minimize generation-loss of the end product. The rationale is that hardware-software compatibility for optimum communication is best understood via hands-on, lab-based exploration of multimedia fundamentals — emphasizing end-product design, concept development, and collaborative techniques used in professional multimedia prototyping. Students also learn about hardware/software options including image editing, digital video, and input/output concerns, covering interface design, web animation and interactivity, video and audio for the web, and interactive end products.

The course is based on the idea that most online identities today are "rented" (Instagram, LinkedIn, etc., which can change rules or disappear). A personal website is owned rather than rented — the course teaches enough code to build one, aiming not just to teach students to make websites but to give them a new perspective on the web as a space, engaging with "indieweb" culture, becoming participants who tend their own digital garden rather than spectators. Code is always in service of design and creative expression.

**Week 1:** Internet archaeology (GeoCities, the Wayback Machine, Marginalia, "the small web"), then fundamentals — HTML, CSS selectors and styling, DevTools, the box model, flexbox and CSS grid. Tools: VS Code, Live Server, GitHub Desktop, Netlify for CI/CD publishing. By day two, students have a basic website online; by week's end, they typeset a piece of writing into a well-designed webpage incorporating layout, images, and type.

**Week 2:** Web frameworks from first principles (Astro, scoped CSS, markdown content, slots, props, components, layouts — LLM-assisted building is noted as a good learning approach). Personal sites begin to take shape; focus shifts to the IndieWeb and digital gardens, basic web design principles, visual hierarchy, content-first wireframing in Figma, and design tokens.

**Week 3:** Build week with structured sprints from design to layout to components to polished, fully-owned websites.

## Course Outcomes (COs)

Students gain a new perspective on the web as a space, engaging with "indieweb" culture, and become participants who tend their own digital garden — building a personally-owned website through code, with design and creative expression as the driving purpose (not code for its own sake).
