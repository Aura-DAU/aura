# List of Completed Programs under the Anchor Institute Program (AIP) at DAU/DA-IICT

## Overview

Complete year-by-year list of faculty training programs conducted under DA-IICT's Anchor Institute Program (AIP), which trains faculty from other Gujarat engineering colleges. Coordinated by AIP Officers Parth Vayeda (through 2023) and Jayesh Patel (2023 onward), 079-68261662.

## Main Content

### 2017-18 (3 programs)
Digital System Architecture (Verilog HDL/FPGA), Relational Databases, Best Practices in C/Modern C++ — all 5-day trainings, 12-21 participants each.

### 2018-19 (15 programs)
SOA with Cloud, VLSI front-end design (Cadence), Algorithm Analysis & Design, Digital Signal Processing, Computer Networks, Operating Systems (x2), Device Modeling & Circuit Simulation, Digital/Analog Communication Systems, Image Processing (VLSI), Multicore Processor Architecture & Parallel Programming, Data Structures (with IIScB collaboration), Software Engineering & Programming Innovations, Advanced .NET/C#, Real-time & Embedded Systems. 5-29 participants per program.

### 2019-20, 2020-21, 2021-22
**No programs held** (pandemic-affected years).

### 2022-23 (1 program)
Introduction to Java Backend (Online, 6 months, industry partner Rishabh Software) — 26 participants.

### 2023-24 (5 programs)
Introduction to ML with Python (Online, 4 months, 34 participants), Advanced Data Science & Analytics (Rishabh Software, 24 participants), AI in VLSI Design (with IIT Jodhpur, IIT Ropar, ABV-IIITM Gwalior, 38 participants), Data Analysis using Python (38 participants, one session cancelled).

### 2024-25 (3 programs, all cancelled)
Human Experiences through Interaction Design, Arduino-Based Embedded System Design, Device Modeling and Circuit Simulation — all cancelled.
