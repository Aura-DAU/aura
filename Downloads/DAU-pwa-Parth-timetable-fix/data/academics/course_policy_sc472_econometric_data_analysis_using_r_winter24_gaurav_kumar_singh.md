### Course Description

The course “Econometric Data Analysis Using R” introduces some basic statistical tools that can be
used to answer to business problems in a data-driven fashion. By econometrics the course means
exploration to regression techniques. The course highlights the importance and limitations of
different data structures such as cross-section data, panel data and time-series data. Overall, the
course enables to appreciate issues related to statistical inference and ways to resolve them.

The course uses R software for statistical analysis.
