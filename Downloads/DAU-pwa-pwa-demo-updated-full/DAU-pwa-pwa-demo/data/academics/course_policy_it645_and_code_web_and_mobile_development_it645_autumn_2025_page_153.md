# and code: Web and Mobile Development (IT645) (IT645)

## Main Content

Course name and code: Web and Mobile Development (IT645)

Course placement: core course for M.Sc.(IT) Sem III

Course credits: L-T-P (3-0-2-4)

Course instructor: Shruti Bhilare


|  | The objective of this course is to provide an overview of the building blocks of a |
|---|---|
| functional webpage and to understand the frontend and backend technologies that power the modern |  |
| websites and mobile applications. It will help learn skills to develop dynamic webpages and integrate APIs |  |
| through Javascript-enabled frontend framework, ReactJS and backend of NodeJS. |  |


hybrid mobile application development technology, React Native for iOS as well as Android operating
systems.

Course content: The basic building blocks of webpages: HTML5, CSS3 and Javascript. Additionally,
front-end framework for creating dynamic web pages (ReactJS) and the NodeJS and MongoDB backend
comprising the MERN stack and React Native. Detailed course content is listed below.

Prerequisites: HTML, CSS, programming skills,
