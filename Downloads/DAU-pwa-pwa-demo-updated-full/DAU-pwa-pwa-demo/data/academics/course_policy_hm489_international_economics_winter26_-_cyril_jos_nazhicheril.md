# HM489 International Economics Winter26

## Main Content

| HM 489- International Economics (Winter 2026) |
|---|
|  |


Instructor: Cyril Jos, FB-4

Course Placement- International Economics is an Elective course for third year (6th semester)
BTech program.


|  |  |  |
|---|---|---|
| Course format: It is 3 hours lecture every week. |  |  |
|  |  |  |
| Objective- The aim of this course is to provide students with a grounding in the principles of |  |  |
| international economics so that they understand the world trade and payment system. The |  |  |
| course covers the pure theory of trade and extensions thereof. Open-economy macroeconomics, |  |  |
| including the determination of the exchange rate, is discussed and consequences of capital |  |  |
| mobility are explored. The balance of payments adjustment policies under alternative |  |  |
| exchange-rate regimes is discussed. Political economy issues in trade are also introduced. |  |  |
|  |  |  |
|  |  |  |
| Detailed Course Contents |  |  |
| Topic Name | Content (2 -3 lines per 4 – 6 lectures) | No. of lectures |
| Introduction and International Trade Theory | Globalization of the World Economy, Mercantilism, Absolute advantage, Ricardian model of Comparative Advantage, Factor endowments and Hekscher Ohlin theory, Rybczynski theorem | 6 |
| Economies of Scale, Imperfect Competition and International Trade | Monopolistic competition and Trade, Significance of Intra-industry Trade, and Dumping and Economies of Dumping. | 4 |
| International Trade Policy | Basic Tariff Analysis, Effects of a Tariff : Consumer and Producer Surplus, The Partial Equilibrium Analysis of Tariffs, The General Equilibrium Analysis of Tariffs, Other Instruments of Trade Policy. | 6 |
| Political Economy of Trade Policy | Political Arguments for Free Trade: Free Trade and Efficiency, International Trade Agreements: from the GATT to WTO, Free Trade Areas versus Customs Union, Trade Creation and Trade Diversion. | 4 |
| Exchange Rates and Open Economy Macroeconomics | Foreign Exchange Markets and Equilibrium in the Foreign Exchange Market, Exchange Rate and Relative Prices, Interest Parity: The Basic Equilibrium Condition, | 6 |
