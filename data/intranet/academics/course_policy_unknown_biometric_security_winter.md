# Biometric Security (UNKNOWN)

## Overview

This document presents the detailed policy and syllabus structure for the course Biometric Security (UNKNOWN). It includes details on course objectives, credits, prerequisites, syllabus content, evaluation schemes, and contact information where available.

## Main Content

Course name: Biometric Security

Course Placement:  Technical elective open to B.Tech. ICT Semester VI and VII,  MSc (Data Science) 
and M.Tech sem II students

Course credits: LTP-C (3-0-2 -4)

Prerequisites:

 
Image Processing OR computer vision  
 
Machine Learning 
 
Python

Course Outcome: 
After the successful completion of the course the students should:

i. 
develop an in-depth understanding of the biometric recognition systems and all associated 
aspects;  
ii. be able to comprehend and present state-of-the-art research papers; 
iii. be able to work on a specific research problem as part of the project work and, 
iv. be able to write technical report

Course content: 
Introduction to biometrics: basic processing pipeline, biometric recognition including identification and 
verification, biometric traits or modalities, specific characteristics of biometric traits, different biometric 
modes: face, speech, iris, palmprint, finger-vein, palm-vein, fingerprint. Evaluation metrics: impostor 
scores, genuine scores, FAR, FRR, EER, GAR, DET curve, CMC curve, Receiver operating characteristics, 
Face recognition: state-of-the-art in face biometrics, deep learning architecture pipeline, hand-crafted 
features, vascular biometrics: Acquisition, vascular biometric traits: palm-vein, finger-vein, dorsal hand-
vein, iris. Attacks: Presentation attacks on biometric systems: real-world attack instances, different defense 
measures, Adversarial attacks using physical accessories, morphing attacks, multi-modal biometric 
systems: fusion at different levels: image-level fusion, score-level fusion, and decision-level fusion. 
Cancelable biometrics, secure and privacy preserving biometrics, face de-identification, cross-domain/ 
heterogeneous recognition, Person re-identification.
