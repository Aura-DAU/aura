## Main Content

DS604, Introduction to Data Management (Autumn’2025)

Course Placement: M.Sc. (Data Science), Core, Semester–I

Course format: 3 Lecture hours and 2 hours Lab

Course Instructor: PM Jat, 2203, Faculty Block 2

Course Content:

Introduction to Data Management is designed to provide students with a foundational 
understanding databases that spans to

(1) Data, databases, data models, data representations and operations on them. Roles

of metadata, and database management systems 
(2) Relational Model as database implementation model, its concepts, key constructs,

and manipulations 
(3) Manipulation Operations through Relational Algebra visa-a-vis SQL 
(4) ER Modeling: Common artifacts of ER Modeling, and their uses in depicting a

database design in an implementation independent manner. 
(5) Formal approaches for Designing and evaluation of relational databases 
(6) Techniques to created database server hosted programs that run in the close

proximity of the data providing efficient execution and provide highest level of 
shareability of the functionality 
(7) Technique for efficiently storing the data that provide efficient access for

answering the queries 
(8) Concepts of Query Optimization and Execution for relational systems. 
(9) Concerns and Techniques to address those concerns while concurrent Transaction

Processing and Technics that are used in dealing with concurrent

Labs and Assignments:

During Lab hours, students practice concepts learned in theory and would be asked to 
design and implement a database system for a mid-size real-life scenario.

Text Books:

1. Fundamentals of Database Systems, Ramez Elmasri and Shamkant B. Navathe, Pearson Education 
2. Database System Concepts by Avi Silberschatz, Henry F. Korth, S. Sudarshan, TMH

Evaluation plan:

1. Two Mid Semester Exams: 30% 
2. Project: 20% 
3. Lab Evaluation: 20% 
4. End Semester evaluation: 30%

Course Outcomes:

The database is one of the core competency areas for data science students. Through this course, 
students develop the ability to

 
Design and implement Database systems.
