# HTTPS - MC

## Overview

This document presents the detailed policy and syllabus structure for the course MC (HTTPS). It includes details on course objectives, credits, prerequisites, syllabus content, evaluation schemes, and contact information where available.

## Main Content

MC 122 
Object Oriented Programming (AY Winter 2025-26)

Instructor: Dr. Ankit Vijayvargiya, Faculty Block-4 
 
Course Placement: B.Tech. (MNC), Semester-II 
 
Course Format: 2 Lecture hours and 2 Lab hours. 
 
Course Content: The course begins with a recap of structured programming, revisiting 
variables, conditionals, loops, arrays, functions, and modular program design. It then 
introduces the principles of Object-Oriented Programming, covering classes, objects, 
constructors, inheritance, polymorphism, abstraction, and encapsulation. Students also learn 
exception handling, file handling, and basic object-oriented design concepts, with laboratory 
work focused on implementing OOP concepts and developing small applications. 
 
Books: 
1. Introducing Python: Modern Computing in Simple Packages by Bill Lubanovic, 
O'Reilly, 2nd Edition, 2019. 
2. Python 3 Object-oriented Programming by Dusty Phillips, Packt Publishing, 2nd 
Edition, 2015. 
 
Related Resources: 
1. Visual Studio Code: https://code.visualstudio.com/download 
2. Anaconda: https://www.anaconda.com/download 
3. Python 3.9: https://www.python.org/downloads/

Assessment Method: i) Attendance: 10%, ii) Mid-sem Exam-20%, iii) End-sem Exam: 40%, 
iv) Other components (Project, Viva, Quiz and Assignments): 30%.

Course Outcomes: By the end of the course, students will be able to recall and use structured 
programming concepts, construct classes and objects to model real-world problems, and apply 
encapsulation, abstraction, inheritance, and polymorphism effectively in program design. They 
will also be able to implement robust programs using exception handling, file operations, and 
modular programming practices. Ultimately, students will gain the ability to analyze problem 
statements and develop complete object-oriented applications on, integrating appropriate 
design and coding principles.
