Course Description:

This course aims to introduce the concept of data structures, their indispensability in 
implementing algorithms, and how they enhance performance. Extensive coverage of the 
well-known and essential data structures, such as arrays, linked lists, queues, stacks, hash 
tables, binary search trees, AVL trees, red-black trees, 2-3-4 trees, and heaps, along with 
associated routines/algorithms such as dictionary operations, order statistics, sorting, will 
constitute the contents of the course.

Course Outcomes:

After successful completion of the course, the student will have the ability to -

●​ Utilize appropriate simple data structures in problem-solving

●​ Understand data abstraction and order statistics

●​ Understand program efficiency through analysis of algorithms

Tentative Course Plan1:

| Units | Topics | Number of
Lectures |
|---|---|---|
| Preliminaries | Representation of data on a computer, data types & array and
linked list representations, ways of representing programs and
associated data on computers | 3 |
| Analysis Tools | The notion of the running time of an algorithm, Recurrences,
and Parameters of Performance | 3 |
| Dictionary
Operations | Find, Max, Min, Successor, Predecessor (query operations);
Insert, Delete (modify operations) | 6 |
| List Data | Stacks, queues, and variants implementation using arrays and
linked lists, as well as hashing. | 6 |
| Sorting | Comparison-based sorting algorithms, Other sorting
algorithms, lower bounds for comparison-based sorting
algorithms, Best-case, worst-case, and average-case running
times. Heap Sort, Bubble Sort, etc. | 9 |
| Order
Statistics | Maximum and minimum elements of a set, fni ding median,
searching for an element of a given rank, fni ding the rank of a
given element, ranks of a subset of elements, maintaining rank
information for a dynamic set | 3 |
| Trees | Heaps, Binary search trees (BST), the height of BST, Tries,
Balanced BSTs: Red Black trees, AVL Trees, B Trees. | 9 |
| Graphs | Representation using adjacency matrices and adjacency lists,
Graph searching algorithms, BFS, and DFS | 3 |


1 — This course plan is subject to change without notice.
