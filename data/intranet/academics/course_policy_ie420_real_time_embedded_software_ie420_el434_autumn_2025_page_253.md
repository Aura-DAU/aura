## Main Content

Real Time Embedded Software (IE420 / EL434 / EL518) 
 
Course Placement: B.Tech (EVD) / B.Tech (ICT) / M.Tech (ICT with Spl. in VLSI & ES)  
 
Credits: 3-0-2-4 
 
Course format: 3 hours lecture and 2 hours lab every week.  
 
Course content: This course introduces the design and implementation of real-time embedded 
software systems with strict response-time requirements. It covers embedded hardware, real-time 
operating systems (RTOS), driver configuration, sensor interfacing, and real-time data streaming to cloud-
based platforms. Through lectures and hands-on labs, students develop systems used in applications such 
as healthcare monitoring, smart infrastructure, IoT, and edge computing.

Course Outcomes (COs)

 
CO1: Understand fundamental concepts and distinctions of real-time and embedded systems. 
 
CO2: Analyze and configure hardware drivers and port real-time operating systems. 
 
CO3: Apply software abstraction layers and implement real-time dashboards using GUI 
frameworks. 
 
CO4: Integrate embedded systems with IoT/cloud platforms and stream sensor data in real-time. 
 
CO5: Design and develop real-time data streaming system for practical domains.
