# Soft Computing (IE422) (IE422)

## Overview

This document presents the detailed policy and syllabus structure for the course Soft Computing (IE422) (IE422). It includes details on course objectives, credits, prerequisites, syllabus content, evaluation schemes, and contact information where available.

## Main Content

Soft Computing (IE422)

Instructor: Pushpendra Kumar

Course Placement: Soft Computing (IE422) is an ICT & Technical Elective / MnC Elective.

Course Format: 3 Lecture hours and 2 Lab hours for the 4-credit course.

Course Prerequisites: Basic knowledge of mathematics fundamentals (including discrete 
mathematics), and MATLAB/python.

Course Content: This course is designed for UG students, aiming to build a strong 
foundation as well as advanced understanding of Soft Computing techniques. It starts with 
the basics of soft computing, its characteristics, and how it differs from hard computing. 
The fuzzy logic part covers fuzzy sets, relations, membership functions, fuzzy inference 
rules, fuzzification and defuzzification methods along with their applications. The neural 
network section introduces artificial neuron models, activation functions, perceptrons, 
backpropagation, associative memory, radial basis function networks, and fuzzy neural 
networks. The genetic algorithm module explains the GA framework, encoding, selection, 
crossover, mutation, optimization problems, convergence theory, and fuzzy logic 
controlled genetic algorithms. The course balances theoretical aspects with practical 
applications, enabling students to apply these techniques in real-life and engineering 
problem-solving. Overall, the content equips learners with essential skills in fuzzy logic, 
neural networks, and genetic algorithms, making it relevant for research as well as 
practical implementation.

Text Books:

1.) Timothy J. Ross, Fuzzy Logic with Engineering Applications (John Wiley & Sons, 
2009) 
2.) S. Haykin, Neural Networks and Learning Machines, third Edition, New Delhi, India: 
PHI Learning, 2011. 
3.) S. N. Sivanandam and S. N. Deepa, Principles of Soft Computing (John Wiley & Sons, 
2007). 
4.) D. E. Goldberg, Genetic Algorithms in Search, Optimization and Machine Learning, 
Pearson Education, 2006.

Reference Books:

1.) S. Rajasekaran and G. A. Vijayalakshmi Pai, Neural Networks, Fuzzy Systems 
and Evolutionary Algorithms: Synthesis and Applications, second Edition, New 
Delhi, India: PHI Learning, 2017. 
2.) J. S. R. Jang, C. T. Sun, and E. Mizutani, Neuro-Fuzzy and Soft Computing 
(Prentice Hall, 1997).

Assessment Method: The total grade will be based on lab assignments (30%) and scheduled 
examinations (two in-semesters and one end-semester) (70%).

Course Outcomes:

This course will enable students to understand the fundamental principles of fuzzy logic, 
neural networks, and genetic algorithms, and apply soft computing methods in real-world 
applications such as data analysis, control, and decision-making. Learners will gain both 
theoretical insights and practical problem-solving skills in soft computing techniques. The 
course provides a strong foundation for advanced research or industry roles in artificial 
intelligence, machine learning, and computational intelligence. After successful 
completion of the course, the student will have the ability to:

CO1: Apply fuzzy logic, neural networks, and genetic algorithms to optimization and 
decision-making problems. 
CO2: Recognize the feasibility of using soft computing methods for solving real-world and 
engineering applications. 
CO:3 Demonstrate analytical and computational skills in designing intelligent systems using 
soft computing approaches.

LAB TOPICS

1. Introduction to MATLAB/Python for Soft Computing

o Basic operations, visualization, and toolboxes for fuzzy, neural networks, and

optimization. 
2. Fuzzy Sets and Membership Functions

o Implement triangular, trapezoidal, Gaussian membership functions and visualize

them. 
3. Fuzzy Inference Systems

o Design a simple rule-based fuzzy system (e.g., temperature control, speed

control). 
4. Defuzzification Methods

o Implement Centroid, Bisector, MOM, SOM, LOM techniques with examples. 
5. Membership value assignments

o Intuition, inference, rank ordering 
6. Neural Network Basics

o Implementation of single-layer perceptron and testing with linear separable data. 
7. Multi-Layer Perceptron (MLP) with Backpropagation

o Train an MLP for classification (e.g., XOR problem, digit recognition). 
8. Radial Basis Function Networks

o Design and compare with MLP on approximation/classification tasks. 
9. Hopfield and BAM neural networks

o Qualitative and quantitative analysis 
10. Fuzzy neural networks, Generation of membership functions using NNs

o Qualitative and quantitative analysis 
11. Genetic Algorithm (GA) Operators

o Implement encoding, selection, crossover, mutation on a sample problem. 
12. GA for Optimization

o Apply GA to solve unconstrained single-objective optimization (e.g., minimizing

a nonlinear function). 
13. Integration of all Techniques

o Computing membership functions using genetic algorithms 
o Fuzzy Logic Controlled Genetic Algorithms
