## Course Description

The world is increasingly relying on data collection/analysis for the decision-making process. Presently, an enormous amount of data gets generated every day. However, human beings have relatively constant perceptual and cognitive abilities. It is always difficult or almost impossible to notice mistakes within a dataset, and that makes data visualization particularly important. Data visualization provides a powerful way to communicate data-driven findings and motivate interesting analyses. Effective visual encoding can supplement cognitive calculations with simple perceptual inferences and improve comprehension and decision-making processes. Good visual representations help engage more diverse audiences in the process of analytic thinking.

In this course, students will learn the foundations of information visualization and design. Lab assignments using Tableau will sharpen their skills in communicating using data. The goal of the course is to explore important concepts in human perception, decision-making, color theory, and storytelling, as students get hands-on experience while applying the concepts in lab assignments/course-project.

Short assignments will help students get comfortable with the various techniques discussed during lectures. The assignments will be done using a real dataset. The project will give students an opportunity to apply visualization to a dataset of their choosing.

## Course Structure

| Module | Topic |
|---|---|
| Module 1 | Introduction to Data Visualization and Getting Started with Tableau, what and why, perception and cognition |
| Module 2 | Data Abstraction — Data types, Dataset Types (Tables, fields, etc.), Attribute Types (Categorical, Ordered, etc.), Semantics |
| Module 3 | Task abstraction — Actions and Targets, Analyzing and Deriving |
| Module 4 | Marks and Channels — Using Marks and Channels, Visual Channels and encoding, and Channel Effectiveness |
| Module 5 | Arrangements by Keys and Values, Express Quantitative Values, Separate, Order, Align, Spatial Axis Orientation, Spatial Layout Density |
| Module 6 | Arrange Spatial fields — Geometry, Geographic Data, Scalar Fields, Vector Fields |
| Module 7 | Colors — Theory, HSL, colormaps, categorical vs ordered color, color palettes, color deficiency |
| Module 8 | Manipulate View: Change View over Time, Select Elements, Navigate/facet into Multiple Views. Reduce Items and Attributes, hierarchical and multivariate data |
| Module 9 | Data visualization choices, design principles, presentation and storytelling techniques using multiple visualization idioms such as Scatterplot, bar and line chart, streamgraph, stacked bar chart, Gantt charts, slope graphs, heatmap, histogram, box-plot, radar plot, pie and coxcomb chart, Sankey diagram, ridgeline plot, glyph maps, SPLOM, parallel coordinates, choropleth, symbol maps, cartograms, dot density maps, isosurfaces, tooltips, small multiples, MAUP, and more |
| Case Studies | Anscombe's quartet, John Snow's work on the cholera outbreaks, Charles Minard's chart, visualizing distributions, Bias in Visualization (Misleading visuals, data bias), Uncertainty Visualization, animated bubble charts such as Gapminder Tools, and many more for data analysis and storytelling |

*No lecture-count breakdown per module is available in the source document. Based on availability of time and course progress, data-visualization based thematic paper discussions are also included in the lecture sessions.*
