## Course Description
The course begins with a recap of structured programming, revisiting variables, conditionals, loops, arrays, functions, and modular program design. It then introduces the principles of Object-Oriented Programming, covering classes, objects, constructors, inheritance, polymorphism, abstraction, and encapsulation. Students also learn exception handling, file handling, and basic object-oriented design concepts, with laboratory work focused on implementing OOP concepts and developing small applications.

## Course Structure
| Unit | Topic | No. of Lectures |
|---|---|---|
| 1 | Introduction to Subject, Syllabus, Text and Reference Books Discussion, Objectives, scope, outcomes of the course, and evaluation scheme | 01 |
| 2 | Recap of Structured Programming with Python: programming paradigms (procedural vs. object-oriented); variables, data types, operators; conditionals and loops; data structures (lists, tuples, dictionaries, strings); functions (definition, parameters, return values, recursion, modular design). Lab: basic Python syntax/operators, conditionals/loops/functions programs, recursive functions and modular code. | 05 |
| 3 | Fundamentals of Object-Oriented Programming: classes, objects; principles (Abstraction, Encapsulation, Inheritance, Polymorphism); instance variables/methods, self; constructors (`__init__`) and object lifecycle; class variables, class methods, static methods. Lab: defining classes with attributes/methods, constructors, encapsulation via getters/setters. | 05 |
| 4 | Inheritance and Polymorphism: single, multilevel, multiple inheritance; method overriding; `super()` and constructor chaining; Python Method Resolution Order (MRO); runtime polymorphism, duck typing; operator overloading (`__add__`, `__str__`, etc.). Lab: inheritance hierarchies with overriding, `super()`, operator overloading, polymorphism programs. | 06 |
| 5 | Exception Handling, File Handling & Modular Programming: errors vs. exceptions, exception hierarchy; try/except/else/finally; raising exceptions, custom exception classes; file handling (text, JSON, CSV, binary); modules and packages; overview of standard libraries (collections, datetime, itertools). Lab: exception-handling programs, file read/write, custom modules/packages, standard library usage. | 06 |
| 6 | Object-Oriented Design: UML class diagrams (association, aggregation, composition); modularity, cohesion, low coupling; introduction to SOLID principles (conceptual overview); project design and planning integrating OOP, file handling, exceptions. Lab: design and implement a small application (e.g., student management, inventory, or library system) integrating classes, inheritance, polymorphism, exceptions, and file handling; prepare UML diagrams and document project design. | 05 |
