## Course Description
This course explores how Generative Artificial Intelligence (GenAI) is transforming the practice of software engineering from requirements analysis and design modeling to coding, testing, documentation, and maintenance. Students will learn to leverage large language models (LLMs) and AI-assisted tools to automate and enhance different phases of the software development lifecycle (SDLC).

By the end of the course, students will design and implement an AI-augmented software engineering assistant that applies GenAI principles to real-world programming and engineering tasks.

## Program Structure Context
IT568 is offered as an elective open to both UG and PG students, combining lecture and lab components. It builds on prior software engineering coursework and programming proficiency, and prepares students for GenAI-augmented software engineering roles through hands-on work with LLM tools such as GitHub Copilot, ChatGPT, Ollama, LangGraph, and LangChain.
