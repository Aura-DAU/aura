## Course Description

This course will give students an introductory understanding of embedded systems, including programming the AVR microcontroller/ARM processor based Microcontrollers, VHDL, Hardware/Software Co-Design, interfacing of external peripheral devices to microcontroller, and troubleshooting embedded systems. The course consists of two parts: (i) an interactive lecture section and (ii) hands-on work, which will provide a platform to develop an embedded system from scratch. Students will gain knowledge of embedded system functions, embedded components, embedded software, and coding required for practical implementation of a real embedded system. Students will acquire skills in embedded system coding, microcontrollers, sensors, and actuators to become good embedded system engineers.

Today, world-leading companies are looking for people with expertise in the areas of embedded systems, embedded AI, and edge computing, etc. This course will provide a platform to develop skills that companies are interested in when hiring professionals.

## Course Structure

| Module | Topic | No. of Lectures |
|---|---|---|
| Module 1 | Introduction: Embedded Systems Overview (1); Design Challenges — Optimizing Design Metrics (1); Processor and IC Technologies (1); Design Technology and Trade-offs (1) | 4 |
| Module 2 | Custom Single-Purpose Processors: Binary Information Implemented with MOS transistors (1); Digital Logic, Logic gates (1); Combinational and Sequential Logic (2); RT-Level Combinational and Sequential Components (1); Basic Computer Architecture (1); Finite State Machines/FSM (2); Optimizing Datapath (2); Hardware Description Languages — Verilog HDL (2); Field Programmable Gate Array/FPGA (1) | 13 |
| Module 3 | Microcontroller Based on Cortex-M Class Processors/AVR microcontroller: AVR microcontroller, ARM/Cortex family microcontrollers (1); AVR microcontroller, ARM Assembly Language (3); Introduction to Embedded C (1); Mixing C and Assembly (1); Developing programs with ARM/Cortex microcontrollers (3); Peripheral Drivers Development (2); Introduction to Keil µVision (1) | 12 |
| Module 4 | Real-Time Interfacing: Introduction to Input/Output (1); SysTick Timer (1); ARM interrupts and interrupt processing (1); GPIO Polling and Interrupt (1); UART-Serial Interface (1); Analog I/O Interfacing, I/O Synchronization, RS232, I2C, CAN (2); USB Protocols, Bluetooth (2) | 9 |
| Module 5 | Implementation of Embedded Systems: Open-Loop and Closed-Loop Control Systems (1); Example — Self-Driving Car (1); ADC and DAC (1); IMU (Inertial Measurement Unit), Image Sensor, Pressure Sensor (2); Servo-Motor, Pulse-Width-Modulation (PWM) (1); Proportional-Integral-Derivative (PID) Controller (1); Integration of Sensors and Motors with Raspberry Pi/Arduino Boards (1) | 8 |
| Module 6 | Memory: Introduction (1); Common Memory Types — ROM, RAM, EEPROM, SRAM (3); Memory Hierarchy and Cache (1); Advanced RAM, DRAM (1); Memory Management (1) | 7 |
| Module 7 | IC Technology: Full-Custom IC Technology (2); Semi-Custom IC Technology (2); Programmable Logic Device IC Technology (1); Design Technology — Automation and Synthesis (2); Verification — Hardware/Software Co-Simulation (2) | 9 |
