## Course Description
Machine learning is a B.Tech MnC Core course in the 6th semester, and an ICT elective course for B.Tech-ICT, ICT+CS 3rd year (6th Semester). Course format: 3 hours' lecture and 2 hours' lab every week.

The objective of this course is to introduce different classical techniques for machine learning such that the students can understand the working principle of different techniques. The course shall also help the students to address different real-life problems with machine learning techniques. Moreover, the project part of the course is completely devised to encourage students to explore the area of machine learning through research and development.

**Course Content:**
1. Regression – Linear regression, Convexity and gradient descent algorithm, Vectorization, Feature Scaling, Concept of Regularization, Normal Equation, Probabilistic Linear Regression, Overfitting, Ridge regression, The Lasso, Basis Functions.
2. Resampling, Model Selection – Generalization Error, Model Capacity, Cross-validation, The Bootstrap, Bias-Variance Decomposition.
3. Classification – Distance Based Classification, K-NN, Naïve Bayes Classifier, Perceptron, Logistic regression, Softmax, Decision trees, Boosting, Random forest, Support Vector Machine.
4. Clustering – K-Means, Gaussian Mixture Model.
5. Optimal Projection of Data – Principal component analysis, Linear Discriminant Analysis.
6. Neural Network – Representation, Forward propagation, Back Propagation.
