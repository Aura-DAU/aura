## Course Description

This course aims to prepare students to implement different data structures that are taught in the IT205: Data Structures course, using the C++ programming language. The course begins with programming paradigms and gradually introduces essential object-oriented concepts such as classes, objects, encapsulation, constructors, destructors, inheritance, and polymorphism. These object-oriented concepts are essential to implement linear data structures such as stacks and queues and non-linear data structures including binary trees, heaps, and graphs.

## Program Structure Context

IT206 Data Structure Lab using OOP is a Core course for B.Tech. Semester II (Sections A/B) students, with a 2-credit structure (1-0-2). Its associated theory course is IT205 (Data Structures, 3-0-0). It requires Introduction to Programming (C) as a prerequisite, and forms a foundation for the CS/IT stream of courses.

## Additional Notes

- This lab course is tightly coupled with IT205 (Data Structures), sharing the same weekly schedule dates and exam periods, and follows the same "Decipher-o-Cipher"-free but otherwise parallel course structure.
- The course teaches C++ and object-oriented programming as the implementation vehicle for the data structures taught theoretically in IT205.
