## Course Description

This course covers five advanced statistical topics used extensively by data scientists:

1. **Modelling data using regression:** Regression problem, regression models (parametric & non-parametric), model selection, model estimation & inference, multilevel/hierarchical regression models.
2. **Resampling Techniques (Jackknife & Bootstrap):** Estimation of bias and variance, resampling-based inference (estimation, testing, and prediction).
3. **Bayesian Data Analysis:** Frequentist versus Bayesian inference, prior & posterior distributions, credible intervals, Bayes' factor.
4. **Missing Data Analysis:** Different missingness mechanisms, different imputation methods, EM Algorithm.
5. **Causal Inference:** Causation versus correlation, potential outcome framework for causal inference, causal inference using data from (i) randomized experiments, (ii) observational studies, (iii) natural experiments.

## Course Structure

| Section | Topic | Content | No. of Lectures |
|---|---|---|---|
| Modelling Data Using Regression | General regression problem | The general model, Explanation or Prediction, Regression function, Trade-off between predictive accuracy and explanation | 2 |
| | Linear regression | The model & assumptions, estimation, inference, measures of model fit, detection of outliers and leverage points, handling heteroscedasticity | 5 |
| | Logistic regression | The model & assumptions, interpretation of coefficients, estimation, inference, evaluating/checking/comparing fitted logistic regressions, identifiability and separation | 2 |
| | Generalized linear models | Poisson regression, logistic-binomial model, probit regression, ordered and unordered categorical regression, robust regression using t-model | 3 |
| | Multilevel regression | Varying-intercept and varying-slope models, clustered data, repeated measurements, time-series cross sections, other non-nested structures, indicator variables and fixed or random effects | 3 |
| Resampling Techniques | Jackknife | The jackknife estimate of bias and variance of sample median, sample trimmed mean, ratio estimate and regression coefficients | 2 |
| | Bootstrap | Parametric bootstrap, smoothed bootstrap, bootstrap methods for more general problems, bootstrap estimate of bias, non-parametric bootstrap, bootstrap confidence intervals, bootstrap P-values | 5 |
| Bayesian Data Analysis | Subjective and frequentist probability | Paradoxes of classical statistical inference, elements of Bayesian inference, priors, posteriors | 4 |
| | Common problems of Bayesian inference | Point estimates, testing using Bayes' factor, credible intervals, testing a sharp null hypothesis using credible intervals, prediction of a future observation | 6 |
| Missing Data Analysis | Missingness mechanisms and traditional methods | Different missingness mechanisms; traditional methods for dealing with missing data (list-wise deletion, pairwise deletion, single imputation methods, regression imputation) | 2 |
| | Maximum likelihood method | Maximum likelihood method for handling missing data, EM algorithm | 4 |
| | Bayesian estimation and multiple imputation | Illustration through examples | 2 |
| Causal Inference | Counterfactuals and potential outcome model | The average treatment effect, the stable unit treatment value assumption | 2 |
| | Estimating average treatment effect | By random assignment, from observational studies, and from natural experiments | 3 |
| **Total** | | | **45** |
