## Course Description
Cryptography is concerned with the mathematical, algorithmic, and implementation aspects of information and network security. The topics in this course include:
- Classical cryptography vs. Modern cryptography — affine cipher, vigenere cipher; Security definition and adversarial assumptions.
- Secret Key Cryptography (SKC): SPN, pseudo-random functions; Modular Arithmetic-1; Block ciphers; Stream ciphers; Modes of operation; Security notion — perfect security, semantic security, provable security, indistinguishability based security, CPA, CCA.
- Hash functions, Pseudo-Random Generators — Properties, Constructions; Message Authentication Codes; Security notion of MAC; Authenticated Encryptions.
- Public Key Cryptography (PKC): Modular Arithmetic-2, RSA, DSA, El Gamal scheme; PKI, Key Management; Security notion — IND-CPA, IND-CKA.
- Advanced Topics and Applications — Secret sharing scheme; Secure Multiparty Computation; Identity-based cryptography.
