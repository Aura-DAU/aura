## Course Description

Collection of correlated databases distributed over a cluster of servers can facilitate scalable query processing. This course includes foundational work, recent developments, and trends in scalable database management systems. Modern data storage and query processing for parallel and distributed databases will be discussed. Students will work on research projects in the domain of modern distributed data storage and query processing during labs. Students will use various SQL and NoSQL database management tools for implementing their research ideas.

---

## Course Outcomes (COs)

The course will make students understand various fundamental concepts on which Distributed Databases work. Students will have some hands-on experience with distributed database technology and tools through a series of assignments and a project. They will also learn some NoSQL technologies like Graph tools.

## Course Structure

| Unit | Topic | Lecture Hours |
|---|---|---|
| 1 | Overview, Basic definitions | 2 |
| 2 | Relational Model basics: Relational Algebra, SQL, Query Processing | 4 |
| 3 | Introduction of Distributed Databases, Distributed architecture, Distributed Storage | 4 |
| 4 | Distributed database design considerations and strategies: fragmentation, distribution and replication models | 8 |
| 5 | Distributed and Parallel Query Processing, scalability | 2 |
| 6 | Query Localization, Query Optimization, query cost estimation | 6 |
| 7 | Distributed transaction management: concurrency control, crash recovery | 4 |
| 8 | Various data models: SQL and NoSQL databases, RDF and graph databases | 4 |
| 9 | Research issues in modern distributed database management | 6 |
| **Total** | | **40** |
