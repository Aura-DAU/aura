## Course Description

Many problems in computer science are known to be "hard." It is computationally very expensive to solve these exactly. The aim of this course is to learn various techniques to solve such problems in an approximate manner. The course will discuss algorithmic techniques like greedy algorithms, local search, approximation schemes, LP-based algorithms, randomized algorithms, and a few others. For each technique, the course will cover one or more problems and also focus on detailed analysis of the approximation obtained.
