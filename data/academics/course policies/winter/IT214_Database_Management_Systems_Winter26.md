## Course Description

This course is intended to give a solid background in database design and implementation with a focus on the relational model. The course covers data modeling, theory of the relational model, and querying relational databases using Relational Algebra and SQL. It also covers the theory of Functional Dependencies, Normal Forms, Decomposition Principles and Algorithms. Students also learn and practice creating stored procedures and accessing databases in host programming languages. The course also introduces Storage and Indexing structures, Query Execution, and Transaction Processing concepts.

During lab hours, students practice concepts learned in theory and are asked to design and implement a database system for a mid-size real-life scenario.

## Course Structure

| Unit | Topic | No. of Lectures |
|---|---|---|
| 1 | Introduction to Databases: Database, Instance, Schema, and Metadata (1); Conceptual and Implementation database Models (1); 3-Schema Architecture — Data and Operation Independence (1) | 3 |
| 2 | Relational Model and Operations on Relations (all operations discussed in Relational Algebra and SQL side by side): Relational Concepts (1); Basic Relational Operations — RA and SQL (2); Set Operations — RA and SQL (1); Division Operation — RA and SQL (1); Aggregation Operations — RA and SQL (1); More SQL operations (1); Examples — RA and SQL (1) | 8 |
| 3 | Entity Relationship Modeling: Concepts and notations — Entity/Relationship type, instance, and sets (1); Aggregation, Ternary Relationships and case study (1); ER to relational Mapping (1); Enhanced ER Modeling and EER to relational mapping (1); Case study discussion (2) | 6 |
| 4 | Database Design: Database Design Concepts and Design Anomalies in relations (1); Theory of Functional Dependencies (2); Normal Forms as a measure of "goodness" of a relation design (1); Decomposition Principles and Algorithms (2); Design Tutorials (1) | 7 |
| 5 | Database Programming: Views and Stored Procedures (2); Triggers (1); Embedded SQL (1); API based access of databases (1) | 5 |
| 6 | Indexes: Database storage file structures (2); Indexing Methods and SQL support (2) | 4 |
| 7 | Transaction Processing: Concepts (2); SQL Isolation Levels (1); Concurrency Control Techniques (2) | 5 |
| 8 | Query Execution and Optimization: Query Execution and Optimization Concepts (2); Algorithms for basic operations (2) | 4 |
