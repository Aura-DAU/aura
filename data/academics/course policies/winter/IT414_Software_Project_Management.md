## Course Description

Practical use of software project management requires understanding of core software design principles, related managerial aspects, an influx of new ideas, and the courage to improve traditional approaches for handling the evolving scenario of the IT industry. As a software engineer and an early career manager, you need to know the methods, workflows, and tools to handle continuously growing complexity and shortened project management cycles. You must be able to work in teams to build high-quality software. In this course, we will introduce the basic concepts of software project management along with some contemporary industry practices. You will also get hands-on experience with project documentation, feasibility analysis, risk handling techniques, etc. that are used when implementing complex software projects through different case studies.

---

## Course Outcomes (COs)

Software Project Management theory introduces students to fundamental principles of software project management as well as risk management principles, along with some related activities carried out in large-scale IT software projects. It also covers key topics including estimation, project planning, scheduling, project reviews, process improvement, etc. This course also addresses topics related to handling outsourced projects and project failures. This course also prepares students for higher-level specialization in software project management courses.

After successful completion of the course, the student will have the ability to:

| CO | Description |
|---|---|
| CO1 | Understand, analyze, plan, manage, and implement software projects. [P1, P2, P12] |
| CO2 | Apply project management principles for implementation/handling software projects using various tools and techniques. [P3, P5, P11] |
| CO3 | Plan, monitor, track, and review software projects in a large group setup. [P9, P11] |
| CO4 | Create software project management documents, detailed project plans, schedules, along with necessary software implementation strategy. [P10, P11] |
