## Course Description

This course covers the engineering of production-grade machine learning systems. It spans the full ML system lifecycle — from data acquisition, containerization, and pipeline orchestration to cloud deployment, security, and MLOps best practices. Students work through hands-on labs, a capstone mini-project, and an end-to-end corporate-style ML project culminating in Kubernetes deployment.

## Course Structure

| Unit | Topic | Details |
|---|---|---|
| Unit 1 | ML Systems, Collaboration & Data Acquisition | Overview of ML System Lifecycle and MLOps in production systems; Object-oriented Python for ML applications; Git/GitHub workflows: branching, merging, pull requests, code reviews; Web scraping & automation (Beautiful Soup, Scrapy); Ethical and legal considerations in data acquisition |
| Unit 2 | Containerization & Kubernetes for ML | Docker for reproducible ML environments; Building, managing, and optimizing Docker images; Kubernetes ecosystem: pods, deployments, services, scaling; Deploying and managing ML workloads on Kubernetes clusters |
| Unit 3 | Data Pipelines, APIs & Cloud Deployment | Building and orchestrating data pipelines (Apache Airflow/Luigi); Scheduling and monitoring ETL workflows; RESTful API development (Django/FastAPI) with MVC, ORM, and security; Cloud platforms for ML (AWS SageMaker, Azure ML, GCP AI Platform); Kubernetes on cloud for scalable ML services; CI/CD for ML, testing, monitoring, logging, A/B testing, cost optimization |
| Unit 4 | Security, Best Practices & Industry Integration | Security & compliance in MLOps (GDPR, ISO); Case studies from e-commerce, finance, healthcare; Lab: End-to-end corporate-style ML project from data acquisition to Kubernetes deployment; Capstone mini-project with CI/CD integration; Industry mentor guest lecture; Certification readiness (AWS Certified ML Specialty or equivalent) |

## Textbooks and References

### Suggested Texts

1. Chip Huyen, *Designing Machine Learning Systems*
   - One of the most practical books on building and deploying ML systems at scale. Covers ML lifecycle, MLOps, data pipelines, experimentation, deployment, and monitoring in industry settings. Written from a product and engineering perspective with case studies from leading tech companies.

2. Emmanuel Raj, *Kubernetes for Machine Learning*
   - Hands-on approach to running, scaling, and managing ML workloads with Kubernetes. Includes examples with Docker, Kubeflow, and cloud platforms. Bridges the gap between data science and production infrastructure.
