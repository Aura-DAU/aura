## Course Description

Course aims: To introduce the systems-engineering mindset needed to build, train, deploy, and maintain large-scale ML/LLM systems in production environments. To develop a working understanding of the hardware-software stack (GPUs, memory hierarchy, precision, compilers) that underlies efficient model training and inference. To equip students with practical techniques for distributed training, inference optimization, and evaluation/benchmarking of ML/LLM systems.

---

## Course Outcomes (COs)

| CO | Description |
|---|---|
| CO1 | Analyze the engineering challenges unique to ML/LLM systems (non-determinism, data-model coupling, distribution shift) and compare deployment paradigms to select appropriate architectures for a given use case |
| CO2 | Evaluate GPU/accelerator architecture and memory hierarchy to apply precision, compiler, and hardware-scheduling techniques that improve compute and memory efficiency |
| CO3 | Design and implement distributed training pipelines (parallelism, fault tolerance, PEFT) for training large models under resource constraints |
| CO4 | Design and optimize inference-serving systems (caching, quantization, routing, edge deployment) to meet latency, cost, and scalability requirements |
