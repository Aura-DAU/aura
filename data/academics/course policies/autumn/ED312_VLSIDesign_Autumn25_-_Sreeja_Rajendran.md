## Course Description

This course introduces design fundamentals necessary to implement VLSI circuits.

---

## Course Outcomes (COs)

After successful completion of this course, students will be able to:

| CO | Description |
|---|---|
| CO1 | Analyze the operation and timing of CMOS circuits, including metastability, synchronization, pipelining, and resource sharing in synchronous digital systems |
| CO2 | Design and evaluate static and dynamic logic circuits such as CMOS, ratioed logic, domino logic, and pass-transistor logic, including flip-flops and latches |
| CO3 | Develop memory architectures with a focus on their layout, read/write mechanisms, and integration |
| CO4 | Apply algorithms for placement and routing in physical design |

## Course Structure

| Module | Topic |
|---|---|
| Module 1 | CMOS Circuits: Timing issues, pipelining, resource sharing, metastability, synchronization |
| Module 2 | Semi & full custom designs: Placement & routing, Algorithms for Physical Design, IO pads & ESD |
| Module 3 | Static & Dynamic CMOS Transistor, Ratioed circuits, domino logic, pass transistor, latches |
| Module 4 | Memory Designs: SRAM, DRAM, ROM, PROM, EPROM, EEPROM, Flash, CAM |
| Module 5 | VLSI Layout of small digital systems using predefined cells using a layout editor, System Verilog, CAD Tools, HDL |

*Lecture counts per module not stated in source document.*
