## Course Description

This course introduces students to the fundamentals of programming and computational problem solving using the C programming language. The course emphasizes structured programming, algorithmic thinking, and hands-on implementation. It covers data types, variables, control structures, functions and modular programming, single and multidimensional arrays, pointers and pointer arithmetic, dynamic memory, and files. It provides a strong foundation for subsequent courses in data structures, system programming, operating systems, and software engineering.

## Course Structure

| Unit | Topic | No. of Lectures |
|---|---|---|
| Unit I: Introduction to Programming and Problem Solving | Introduction to programming and computational thinking; problem-solving methodology, algorithms, flowcharts, and pseudocode; history, features, and applications of C; structure of a C program, preprocessing, compilation, linking, execution, development tools, editors, compiler, debugger, IDE, and coding environment | 4 (2+2) |
| Unit II: Data Types, Variables, and Operators | Tokens, keywords, identifiers, constants, variables, data types, declarations, type modifiers; input/output using printf() and scanf(); arithmetic, relational, logical, assignment, increment/decrement, conditional, bitwise operators; expressions, precedence, associativity, type conversion, and casting | 5 (2+1+2) |
| Unit III: Control Structures | Decision making (if, if-else, nested if, else-if ladder, switch); looping constructs (while, do-while, for, nested loops); jump statements (break, continue, goto, return); pattern-based programming and logical problem solving using control statements | 7 (2+2+2+1) |
| Unit IV: Functions and Modular Programming | Function declaration, definition, prototype, and invocation; parameter passing, return values, scope, and lifetime of variables; storage classes (auto, register, static, extern); header files, modular programming, intro to stack, recursion, coding standards, and reusable program design | 7 (2+2+2+1) |
| Unit V: Arrays and Strings | One-dimensional and multidimensional arrays; array traversal, insertion, deletion, and matrix operations; searching (linear, binary) and basic sorting (bubble, selection, insertion); character arrays, strings, standard string library functions, and string manipulation programs | 7 (2+2+2+1) |
| Unit VI: Pointers and Memory Concepts | Pointer declaration, initialization, and dereferencing; pointer arithmetic, pointers with arrays and functions; dynamic memory allocation (malloc, calloc, realloc, free); stack vs heap, memory layout, common pointer errors (NULL, dangling, wild pointers, memory leaks) | 8 (2+2+2+2) |
| Unit VII: File Handling and Structured Programming Practices | File types, file pointers, and file modes; file operations (fopen, fclose, fprintf, fscanf, fgetc, fputc, fgets, fputs, fread, fwrite); error handling in file processing; coding standards, documentation, debugging, and maintainable programming practices | 4 (2+2) |
| **Total** | | **42** |

*Note: Units I and II share a combined quiz ("Unit 1 & 2 combined"); the source's quiz-count column has been omitted from this table as it is a scheduling detail rather than lecture count — see Additional Notes for the full quiz distribution.*
