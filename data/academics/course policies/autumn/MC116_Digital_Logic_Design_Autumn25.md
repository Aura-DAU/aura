## Course Description

This course provides an introduction and basic understanding of the design and implementation of digital circuits. Topics include number systems, Boolean algebra, combinational and sequential circuits.

**Course Materials/References Overview:** Basic understanding of digital and analog domain, noise margin, number system, binary code, logic gates and related devices, Boolean algebra and simplification. Combinational Circuits: Digital arithmetic, encoders, decoders, multiplexers, de-multiplexers. Sequential Circuits: Latch, flip-flop, register, counter, memory.

## Course Structure

| Week | Module/Topic | Description | Lectures |
|---|---|---|---|
| 1 | Introduction to Digital Systems | Analog vs Digital, signals and domains, noise margin | 1 |
| 2 | Number Systems | Binary, octal, hexadecimal, conversions | 1 |
| 3 | Binary Codes and Logic Gates | Binary codes, basic and universal logic gates | 1 |
| 4 | Boolean Algebra | Postulates, theorems, simplification | 1 |
| 5 | Logic Simplification | Karnaugh Maps, SOP/POS forms | 1 |
| 6 | Combinational Circuits I | Half adder, full adder, subtractors | 1 |
| 7 | Combinational Circuits II | Encoders, decoders | 1 |
| 8 | Combinational Circuits III | Multiplexers, demultiplexers | 1 |
| 9 | Sequential Circuits I | Latches and Flip-Flops | 1 |
| 10 | Sequential Circuits II | Registers and Counters | 1 |
| 11 | Memory Devices | RAM, ROM, basics of memory hierarchy | 1 |
| 12 | Lab Demonstrations / Projects | Practical implementation of combinational and sequential logic | 1 |
| **Total** | | | **12** |

*Note: This Detailed Course Content is labeled a "Tentative Plan" in the source document (Appendix A).*

**Lab Assignments (Appendix B — Tentative Plan):**

| Lab | Description |
|---|---|
| Lab 1: Familiarization of Various Logic Gates | Test AND, OR, EXOR gates on breadboard. Implement one's complement of a 4-bit number A when control input C=1, else leave A unchanged. |
| Lab 2: Binary Arithmetic and Binary Codes | Implement half adder and half subtractor. Design a 4-bit binary to Gray code converter and even parity generator. |
| Lab 3: Four-bit Increment and Decrement Circuits | Implement 4-bit decrementer with control input. Derive expression and design for 4-bit increment-by-2 circuit. |
| Lab 4: Universal Logic Gates | Implement given function using only NAND gates. Design F(A,B,C) = Σm(2,3,4,5) using 2 NAND ICs. |
| Lab 5: Magnitude Comparators | Design and implement 3-bit equality checker and 2-bit greater-than comparator. |
| Lab 6: Study of Adder/Subtractor and Up/Down Counter | Use CD4008 and XOR IC for 4-bit adder/subtractor. Study counter transitions using 4029 IC. |
| Lab 7: Familiarization with Multiplexer and Decoder ICs | Use 8:1 MUX to implement full adder sum function and given logic function. Verify 3-to-8 decoder (74LS138). |
| Lab 8: Design of Counters and Flip-Flop Conversion | Verify D and JK flip-flops. Construct SR from D flip-flop. Design a 3-bit JK counter from 000 to 111. |
