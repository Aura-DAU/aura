## Course Description

This course provides an understanding of the fundamental structures and mechanisms used by an operating system.

---

## Course Outcomes (COs)

After studying this course, students will have an understanding of:

| CO | Description |
|---|---|
| CO1 | The main principles and techniques used to implement processes and threads as well as the different algorithms for scheduling |
| CO2 | The problems related to concurrency, the basic synchronization mechanisms available as well as the techniques used to implement them |
| CO3 | The data structures and components (both hardware and software) that are used to implement virtual memory |
| CO4 | How data structures of a file system serve to map file names to blocks of a storage device |

## Course Structure

*APPENDIX-I: Detailed Course Content (Session-wise/Module-wise)*

| Unit | Topic | No. of Lectures |
|---|---|---|
| Module 1 | Multi-programming: processes and threads, system calls, context switching, types of scheduling, scheduling metrics, scheduling policies | 10 |
| Module 2 | Concurrency and synchronization: race conditions, critical sections, mutual exclusion, Peterson's algorithm, hardware support for locking, spin lock, ticket lock, blocking lock, semaphores, condition variables, implementation issues, deadlocks, lock-free data structures | 10 |
| Module 3 | Virtual memory: logical/physical address spaces, paging, protection, TLB, demand paging, copy-on-write, page replacement policies, implementation issues | 10 |
| Module 4 | File systems: hard-disk drives, device drivers, files and directories, hard links, symbolic links, file system implementation, i-nodes, file layout approaches, crash recovery, journaling, fast file system, solid-state drives, file systems for SSDs | 10 |
| **Total** | | **40** |
