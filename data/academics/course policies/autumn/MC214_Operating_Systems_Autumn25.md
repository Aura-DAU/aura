## Course Description

**Objectives:** This course provides an understanding of the fundamental structures and mechanisms used by an operating system.

---

## Course Outcomes (COs)

At the end of the course, students will have an understanding of:

| CO | Description |
|---|---|
| CO1 | The main principles and techniques used to implement processes and threads, as well as the different algorithms for scheduling. |
| CO2 | The problems related to concurrency, the basic synchronization mechanisms available, as well as the techniques used to implement them. |
| CO3 | The data structures and components (both hardware and software) that are used to implement virtual memory. |
| CO4 | How data structures of a file system serve to map file names to blocks of a storage device. |

## Course Structure

| Unit | Topic |
|---|---|
| 1 | Multi-programming: processes and threads, system calls, context switching, types of scheduling, scheduling metrics, scheduling policies |
| 2 | Concurrency and synchronization: race conditions, critical sections, mutual exclusion, Peterson's algorithm, hardware support for locking, spin lock, ticket lock, blocking lock, semaphores, condition variables, implementation issues, deadlocks, lock-free data structures |
| 3 | Virtual memory: logical/physical address spaces, paging, protection, TLB, demand paging, copy-on-write, page replacement policies, implementation issues |
| 4 | File systems: hard-disk drives, device drivers, files and directories, hard links, symbolic links, file system implementation, i-nodes, file layout approaches, crash recovery, journaling, fast file system, solid-state drives, file systems for SSDs |

*No lecture-count breakdown per unit is available in the source document.*

## Additional Notes

- Lab attendance is mandatory. Students must demonstrate their code for in-lab exercises to a TA as specified in the lab handout. Failure to do so results in lost points. There will be no makeup labs for any reason.
