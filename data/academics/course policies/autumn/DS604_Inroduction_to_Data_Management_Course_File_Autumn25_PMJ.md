## Course Description

Introduction to Data Management is designed to provide students with a foundational understanding of databases that spans to:

1. Data, databases, data models, data representations and operations on them; roles of metadata, and database management systems
2. Relational Model as database implementation model, its concepts, key constructs, and manipulations
3. Manipulation Operations through Relational Algebra vis-à-vis SQL
4. ER Modeling: Common artifacts of ER Modeling, and their uses in depicting a database design in an implementation-independent manner
5. Formal approaches for designing and evaluation of relational databases
6. Techniques to create database server-hosted programs that run in close proximity of the data providing efficient execution and highest level of shareability of the functionality
7. Techniques for efficiently storing the data that provide efficient access for answering queries
8. Concepts of Query Optimization and Execution for relational systems
9. Concerns and Techniques to address those concerns while concurrent Transaction Processing and techniques used in dealing with concurrent transactions
