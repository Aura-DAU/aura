## Course Description

This course focuses on the design and development of Information Retrieval systems. The first part of the course begins with traditional Information Retrieval systems, which include preprocessing, indexing, ranking, retrieval models, and evaluation. The course further explores applications of information retrieval in text classification, clustering, and web search, including link analysis algorithms such as PageRank and HITS.

Based upon these foundations, the second part of the course covers modern Neural Information Retrieval techniques such as learning-to-rank, semantic search, dense retrieval, transformer-based retrieval models, FAISS, and vector databases. The course further explores the application of LLMs in modern IR applications, covering Retrieval-Augmented Generation (RAG), hybrid retrieval, agentic retrieval, multimodal retrieval, and conversational search.

## Course Structure

| Unit | Topic | No. of Lectures |
|---|---|---|
| Module 1 | Basics of IR: Introduction to Information Retrieval, Document Collections and Corpora, Information Needs, Queries and Relevance, Handling unstructured text, Preprocessing pipeline (tokenization, stopword removal, stemming, lemmatization), Inverted Indexing (posting lists, index construction) | 5 |
| Module 2 | Term weighting and classical IR Models: Boolean models, Query formulation, ranked retrieval, TF-IDF weighting and cosine similarity, vector-space retrieval models, Probabilistic Retrieval Model, Binary Independence Model, BM25 Ranking Function, Language Models for IR, Query Likelihood Model, Smoothing Techniques | 8 |
| Module 3 | Experimental Evaluation of IR system: Relevance Judgments, Cranfield Paradigm, Test Collections, Evaluation metrics (recall, precision, F-measure, NDCG, MAP, MRR, Precision@K) | 3 |
| Module 4 | Relevance feedback and Query expansion: Relevance feedback, the Rocchio algorithm for relevance feedback, Pseudo Relevance feedback, and Query expansion techniques | 2 |
| Module 5 | Text Classification and Clustering: the text classification problem, Naive Bayes text classification, text clustering - Flat clustering, Hierarchical clustering | 2 |
| Module 6 | Web search: Search engine architecture, crawling, Web as a graph, Link Analysis, PageRank and HITS algorithm | 3 |
| Module 7 | Neural Information Retrieval: Learning to Rank methods (Pointwise, Pairwise, Listwise Ranking and LambdaMART), Latent Semantic Indexing, Word embedding (Word2Vec), Semantic Search and Dense Retrieval, Transformer Models for Retrieval (Bi-Encoder, Cross-Encoder), Retrieval Re-ranking, Approximate Nearest Neighbor (ANN) Search (FAISS, Vector Databases) | 9 |
| Module 8 | Information Retrieval in the LLM Era: Limitations of Classical and Neural Retrieval Systems, Retrieval-Augmented Generation (RAG) Motivation and Architecture, Hybrid Retrieval (Sparse + Dense Retrieval), Emerging Trends (Agentic Retrieval, Multimodal Retrieval, Conversational Search) | 4 |
| **Total** | | **36** |
