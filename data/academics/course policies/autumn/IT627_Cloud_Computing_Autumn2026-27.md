## Course Description

The students at the end of the course will have the following concepts clear: fundamentals of networking; introduction to socket programming; cloud computing and its evolution; concepts of virtualization; service models of cloud; and Amazon Web Services.

## Course Structure

| Unit | Topic | No. of Lectures |
|---|---|---|
| Module 1 | Introduction to Cloud Computing: Introduction, History, Data Centers, Operating Systems and Network Fundamentals | 6 |
| Module 2 | Cloud Computing Architecture: Fundamental Concepts and models, Cloud Characteristics, Delivery & Deployment Model, Economics of the cloud | 6 |
| Module 3 | Virtualization Techniques: Understanding virtualization, Taxonomies, Techniques of Virtualization, Benefit: Pros & Cons | 8 |
| Module 4 | Principles of Distributed Systems: Elements of Distributed System, Technologies of Distributed Computing, Consistency & Replication | 4 |
| Module 5 | Service Models in Cloud Computing: Infrastructure As A Service, Software As A Service, Platform As A Service | 6 |
| Module 6 | Amazon Web Services (AWS): Identity Access Management, S3, Glacier, EC2, Databases on AWS | 10 |
| **Total** | | **40** |
