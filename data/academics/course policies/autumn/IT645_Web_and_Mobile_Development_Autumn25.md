## Course Description

The objective of this course is to provide an overview of the building blocks of a functional webpage and to understand the frontend and backend technologies that power modern websites and mobile applications. It will help students learn skills to develop dynamic webpages and integrate APIs through the JavaScript-enabled frontend framework ReactJS and the backend of NodeJS. It aims at teaching a hybrid mobile application development technology, React Native, for both iOS and Android operating systems.

**Course content:** The basic building blocks of webpages — HTML5, CSS3, and JavaScript. Additionally, front-end framework for creating dynamic web pages (ReactJS) and the NodeJS and MongoDB backend comprising the MERN stack, and React Native.

## Course Structure

| Unit | Topic | No. of Lectures |
|---|---|---|
| 1 | Overview of HTML5: Selected topics in HTML; HTML document structure, metadata and scripting, sectioning and layout, text content, forms and input, images and multimedia, tables | 3 |
| 2 | Overview of CSS3: Selected topics in CSS; Text and Font styles, Box model, Backgrounds, Flexbox, Grid, positioning, lists, tables, effects, transitions and animations | 5 |
| 3 | JavaScript (Native): Variables, operators, functions (arrow functions); Higher order functions; Arrays and objects, OOP; Asynchronous programming (callbacks, promises, async/await); Fetch API, Geolocation API; Event loop; Event handling | 6 |
| 4 | Front end framework (ReactJS): Introduction to ReactJS, React components, props and render(), lifecycle and lifecycle methods; Build a simple React application; Rendering and updating elements; JavaScript XML (JSX); Component intercommunication; Event handling | 6 |
| 5 | Backend — Server side scripting using NodeJS: Server side programming basics, NodeJS introduction, Node commands; Node runtime environment, Installation (package.json and dependencies), Node modules (HTTP, BodyParser, nodemon etc.); Fetch API, HTTP GET and POST requests, query parameters, route parameters, JSON | 6 |
| 6 | MongoDB: Introduction to document-oriented database, mongo shell commands; Using MongoDB in a server, using callbacks and promises; DB operations — search, insert, update, delete | 3 |
| 7 | Full stack web development (MERN): Putting it all together | 2 |
| 8 | React Native: Introduction to React Native, Setup; Workflow, UI and interaction, connectivity, platform APIs; Modules, Deployment | 8 |
| **Total** | | **39** |
