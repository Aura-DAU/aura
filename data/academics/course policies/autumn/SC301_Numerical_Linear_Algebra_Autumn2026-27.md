## Course Description

A first course in Linear Algebra equips students with a set of concepts and tools to handle finite dimensional vector spaces. These are heavily utilized in a wide range of applications in different fields like Image and Signal Processing, Machine Learning, Data Science, Computer Graphics, Mechanical Engineering, etc. This course studies algorithms for some core Linear Algebra concepts that have been incorporated into libraries like LAPACK, for example, solving linear equations and matrix factorizations like QR, Cholesky, and SVD. There are direct and iterative methods for many of these tools.

These problems, in some instances like those encountered in Data Science, may involve large matrices, which makes it important to study the complexity and stability of these algorithms. The course will examine a wide variety of numerical algorithms, study them from the perspectives of accuracy and stability, and discuss a few applications depending on the available time.

## Course Structure

*Note: The source states these contents are "not necessarily in this order."*

| Unit | Topic | No. of Lectures |
|---|---|---|
| Review of Linear Algebra | Vector Spaces: Rⁿ and Cⁿ, Matrices and Vectors, Linear independence, Rank of a matrix, Subspaces, Eigenvalues and Eigenvectors. Inner products and Norms in Rⁿ and Cⁿ, Orthogonality, Matrix Norms, Spectral Radius | Not specified |
| Review of Number Representation | Integer and Floating point representation, Absolute and relative errors | Not specified |
| Linear Equations | Gaussian elimination, LU decomposition, Partial pivoting, Stability - Condition number, Computational Complexity. Special cases - Tridiagonal systems, SPD matrices. Applications: Numerical Solution of PDEs, Splines. If time permits - Iterative Methods: Jacobi, Gauss-Seidel, Successive over-relaxation (SOR), Steepest Descent, Conjugate Gradient | Not specified |
| Matrix Decomposition - QR and Cholesky | Orthonormal basis from a basis, Methods: Gram Schmidt Orthogonalization, Givens rotations, Householder reflections. Cholesky Decomposition. Applications - Computing determinant, Solving Linear equations, Least Squares | Not specified |
| Eigendecomposition | Symmetric and Unsymmetric Eigenvalue problem. Method: Power iteration, QR iterations, Hessenberg and Schur forms. Applications - Difference and Differential equations, Google Page Rank | Not specified |
| SVD (if time permits) | SVD - Existence, Interpretation, Applications - Least squares, PCA | Not specified |
| **Total** | | Not specified |
