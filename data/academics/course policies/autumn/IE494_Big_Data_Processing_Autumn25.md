## Course Description

Data has taken a different shape in today's time. Modern applications and devices produce data that is very huge, unstructured, and cannot be fitted into a fixed schema. Such data, referred to as "Big Data," does not fit well in conventional storage and processing systems.

A whole new set of techniques and technologies are emerging to process such data. This course teaches various techniques that are used for storing and manipulating "Big Data."

**Labs and Assignments:** There would be a series of lab exercises aimed at practicing concepts learned in theory. Students will also be required to either do a project or a term paper.

---

## Course Outcomes (COs)

Upon completion of this course, students should be able to:

| CO | Description |
|---|---|
| CO1 | Explain why traditional data processing techniques do not work on big data problems. |
| CO2 | Work on some of the popular large data processing frameworks like Hadoop, Spark, and some NoSQL databases. |
| CO3 | Perform various operations like filtering, projecting, aggregation, and OLAP queries on large datasets. |
| CO4 | Appreciate Storage, Indexing, and query execution techniques for big data processing. |

## Course Structure

| Unit | Topic | No. of Lectures |
|---|---|---|
| 1 | Introduction to Big Data: Motivation, Challenges, and Solutions | 2 |
| 2 | Taste of "Big Data Processing" through Google's Big-Query | 2 |
| 3 | Map-Reduce: Technique, Infrastructure, and Programming | 3 |
| 4 | Spark Architecture, RDD Data model and Programming, Data-frame Data Model Programming, Spark-SQL: infrastructure and programming | 4 |
| 5 | Concepts of Data Warehousing and OLAP Queries on Spark | 4 |
| 6 | Overview of NoSQL database systems | 3 |
| 7 | Data Sharding, Replication, and Replica synchronization techniques for modern distributed databases. Eventual Consistency | 3 |
| 8 | One of column family database (Big Table/HBase/Cassandra): Data Model and Programming | 4 |
| 9 | Column Oriented Storage and Column Oriented Databases: Motivation and evolution of modern column store databases. Various Data Layout and Access Patterns | 4 |
| 10 | Implementation of modern column store databases. Vectorized Processing | 6 |
| 11 | Case Studies | 4 |
