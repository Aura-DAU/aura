## Course Description

Introduction to Big Data: motivation, challenges, and solutions. Map-Reduce: technique, infrastructure, and programming. Spark Architecture, RDD, Data-frames/Spark-SQL, their data model and programming interfaces. Concepts of Data Warehousing and OLAP Queries on Spark. LSM Tree - motivation, structure, operations, and implementations; study of LevelDB and RocksDB as LSM Tree implementations. Column Oriented Storage and Column Oriented Databases: motivation and evolution of modern column store databases, various data layout and access patterns, vectorised processing; study of implementation of Monet-DB/C-Store. Overview of NoSQL database systems; study of implementations of Amazon's Dynamo-DB and Google's Big Table.

## Course Outcomes (COs)

Upon completion of this course, students should be able to:

| CO | Description |
|---|---|
| CO1 | Explain why traditional data processing techniques do not work on big data problems |
| CO2 | Work on some of the popular large data processing frameworks like Hadoop, Spark, and some NoSQL databases |
| CO3 | Perform various operations like filtering, projecting, aggregation, and OLAP queries on large datasets |
| CO4 | Appreciate storage, indexing, and query execution techniques for big data processing |
