## Course Description

Discrete Mathematics provides the mathematical foundation for advanced studies in Information Technology, Computer Science, Artificial Intelligence, Cybersecurity, Data Science, and Network Analysis. This course introduces mathematical reasoning, logic, proof techniques, combinatorial analysis, recurrence relations, graph theory, discrete probability, and algebraic structures used in computing systems.

The course emphasizes problem-solving, abstraction, and formal reasoning required for algorithm design, software verification, cryptography, optimization, and computational modeling.

**Course Objectives** — after completion of this course, students will be able to:
- Develop formal mathematical reasoning and proof-writing skills
- Apply counting techniques and discrete probability to computational problems
- Analyze recursive algorithms using recurrence relations
- Model networks and optimization problems using graph theory
- Use number theoretic concepts in cryptography and security
- Apply Boolean logic in computing and digital systems

## Course Structure

*APPENDIX-I: Detailed Course Content (Session-wise/Module-wise); textbook section references (Rosen) are preserved from the source.*

| Unit | Topic | No. of Lectures |
|---|---|---|
| Logic and Proofs (Rosen 1.1-1.8, 5.5) | Propositional logic, Predicate logic and quantifiers, Logic operators, Logic proposition, Introduction to different standard proof techniques, Program correctness | 6 |
| Sets, Functions, Relations (Rosen 2.1-4, 9.1-6) | Sets, Set operations, Functions, Relations, Equivalence relations, Partial orderings, Sequences and summations | 5 |
| Algorithms and Complexity (Rosen 3.1-3) | Algorithms and pseudo-code, Growth of functions, Asymptotic notation, Complexity analysis | 3 |
| Number Theory and Cryptography (Rosen 4.1-6) | Modular arithmetic, Primes and representation of integers, Linear congruences, Cryptography basics | 4 |
| Induction and Recursion (Rosen 5.1-4) | Mathematical induction, Strong induction, Structural induction, and generalized induction, Recursive definitions, Recursive algorithms | 4 |
| Counting Techniques (Rosen 6.1-5, 8.5-6) | Counting Principles, Permutations, Combinations, Binomial coefficients, Pigeon hole principle, Inclusion-Exclusion principle | 4 |
| Discrete Probability (Rosen 7.1-4) | Classical probability theory, Conditional probability, Bayes' theorem, Discrete probability distributions, Expected value and variance | 5 |
| Recurrence Relations (Rosen 8.1-3) | Solving linear recurrence relations, Characteristic roots, generating functions, Divide and conquer algorithms | 4 |
| Graph Theory and Trees (Rosen 10.1-2, 10.4-7, 11.1, 11.4-5) | Graph basics, Representations, Euler path and circuit, Hamiltonian cycle, Complete graph, Cycles, Bipartite graph, planar graphs, Euler formula, Shortest path algorithm. Trees: properties, Spanning trees, Minimum spanning trees | 5 |
| Boolean Algebra (Rosen 12) | Boolean functions, Logic gates, K-maps | 2 |
| **Total** | | **42** |
