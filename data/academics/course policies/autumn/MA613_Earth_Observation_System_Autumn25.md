## Course Description

Studying the earth's surfaces can be possible using conventional means like traversing or ground survey. Although this is a sound technique for studying details with the help of various ground-based instrumentation, studying the regional relationship of earth features and various processes (past or present) is not possible without the use of appropriate technology. It is in this context that technologies like satellite-based remote sensing and Geographic Information System (GIS) are relevant.

## Course Structure

| Unit | Topic | No. of Lectures |
|---|---|---|
| 1 | Introduction to remote sensing and its applications | 1 |
| 2 | Electromagnetic radiation, Energy matter interaction — refraction, scattering, absorption, reflection, fundamentals of radiometry | 2 |
| 3 | Spectral signature of earth surface features — vegetation, soil, snow, urban etc. | 2 |
| 4 | Platforms for data collection — ground based, aerial and space based. Satellite orbits — geosynchronous and sun synchronous | 2 |
| 5 | Sensor characteristics — concept of spatial, spectral, radiometric and temporal resolutions | 2 |
| 6 | Space based sensors — multispectral, hyper-spectral, microwave | 2 |
| 7 | Radiometric correction — shot noise, line and pixel drop out, line start correction, striping | 1 |
| 8 | Atmospheric corrections — absolute and relative atmospheric corrections | 1 |
| 9 | Geometric corrections — satellite attitude corrections, corrections for slope and aspect | 1 |
| 10 | Introduction of GIS, datum and coordinate system | 2 |
| 11 | Geographical data types, GIS data model, Map projection | 2 |
| 12 | GIS database organization — Geographic Data Formats, Topology and Spatial Relationship, Spatial Data Quality* | 3 |
| 13 | GIS Operational Procedures, Queries in Spatial Database, Overlay Operations, Spatial Operations, Buffer Analysis, Raster Analysis Operations* | 3 |
| 14 | Map accuracy and GIS errors, Geostatistical Tools for Spatial Analysis* | 2 |
| 15 | Image enhancement — linear and non-linear enhancement, band ratio, neighbourhood raster operations, spatial filtering, principal component analysis, vegetation indices* | 2 |
| 16 | Pattern recognition and Image classification — supervised and unsupervised approach* | 3 |
| 17 | Machine learning and neural network in remote sensing | 2 |
| 18 | Introduction to SAR (Synthetic Aperture Radar) | 2 |
