## Course Description

The students after completing the course will get a basic overview of calculus, linear algebra, differential equations, complex analysis and numerical analysis. Students will get an insight into the fundamentals of these topics and their vast applications. In some of the tutorials, computer programming will be used to visualize and understand the solutions. All outcomes will be assessed with homework, quizzes and exams.

---

## Course Outcomes (COs)

At the end of the course, students will be able to:

| CO | Description |
|---|---|
| CO1 | Understand and define limit, continuity, and differentiability of a function at a point |
| CO2 | Evaluate limits using the definition and using algebraic properties of limits |
| CO3 | Compute indefinite and definite integration and its application |
| CO4 | Interpret the area bounded by curves, volume of a solid of revolution as a definite integral |
| CO5 | Represent a system of linear equations in matrix and vector form |
| CO6 | Solve systems of linear equations using matrices |
| CO7 | Solve real-life problems using matrices |
| CO8 | Find and understand determinants and linear transformations |
| CO9 | Find eigenvalues and eigenvectors of a square matrix and their applications |
| CO10 | Understand vector algebra and vector calculus |
| CO11 | Form ODEs of first and second order and learn about their solutions |
| CO12 | Understand the concept of a general solution, a particular solution and initial conditions |
| CO13 | Draw slope fields by hand and using a computer |
| CO14 | Solve first-order ODEs (linear and nonlinear) using different methods |
| CO15 | Solve second-order linear ODEs with constant and variable coefficients |
| CO16 | Form PDEs and learn about their solutions and applications |
| CO17 | Understand complex numbers and represent them in polar form |
| CO18 | Find complex differentiation and integrations |
| CO19 | Find roots using different numerical methods |
| CO20 | Numerically integrate a function |

## Course Structure

| Sl. No. | Topic | No. of Lectures |
|---|---|---|
| 1 | Calculus — Limit, continuity, differentiation, application of derivatives, integration, definite integrals, method of substitution, integration by parts, application to finding area and volume, double and triple integrals, improper integrals | 10 |
| 2 | Linear Algebra — System of linear equations, matrix addition, subtraction, multiplication, determinants, rank of a matrix, eigenvalues, eigenvectors and applications | 6 |
| 3 | Vectors — Vector algebra, products of vectors, vector triple product, vector equations, differentiation and integration of vectors, vector calculus | 7 |
| 4 | Differential Equations — Formation and solution of ODE, solution of first order ODEs, linear inhomogeneous second order ODEs, free and forced oscillators and applications; formation and solution of PDEs, second order linear PDE, diffusion equation and applications | 8 |
| 5 | Complex Numbers — Complex numbers and their properties, polar representation, Euler's formula, exponential form | 6 |
| 6 | Numerical Methods — Newton's method for finding roots, numerical integration methods, finite element method | 4 |
| **Total** | | **41** |
