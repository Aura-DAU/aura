## Course Description

This course aims to introduce problem-solving techniques using programming to help students develop analytical and logical skills. The course starts with basic concepts of computer programming and follows by building up knowledge in program development, deployment, and testing to solve computational problems. The course also provides visualization of memory and time requirements for solving problems using the C programming language. The coverage of this course includes problem-solving techniques, flow charts, algorithm development, pseudocodes, and implementation of algorithms using C programming.

Course topics include primitive data types, control structures, structured programming, arrays, strings, functions, and pointers, including efficient memory allocation and deallocation.

The course will also cover some ways to constructively use concepts from GenAI tools like LLMs to supplement programming. The lab course IT113 is closely coupled with this course.

## Course Structure

| Unit | Topic | No. of Hours |
|---|---|---|
| 1 | Core C: Variables, Types, Assignment, Operators, Expressions, Branching and Looping; Solving problems by representing solutions as pseudocode; Mapping pseudocode to C programs; Arrays; Functions, passing by value; Scoping rules; Basic I/O and File I/O using standard C library | 20 |
| 2 | Tools: Editor, Compiler, Debugger, Make, and Shell commands (Linux/gedit/gcc/gdb/make/bash used for this course); Multi-file programs | 4 |
| 3 | Pointers: Pointers, Pointer arithmetic, Function — pass by reference, Command line arguments, Dynamic memory allocation, Struct and linked list | 10 |
| 4 | Recursion: Basic concepts, Solving simple problems using recursion, Performance comparison with iterative solutions | 4 |
| **Total** | | **38** |

## Additional Notes

**Course Conduct and Grading Policy (For IT112 and IT113):**
- Students are supposed to be present for all lectures and lab sessions.
- If attendance falls below 70%, a student will receive an F grade. (An institute-wide detailed policy will be communicated separately.)
- All lab assignments (IT113) must be completed, failing which zero marks will be awarded for the lab course. One makeup lab session will be scheduled at the end of the semester for students who miss a session due to any reason. For special medical cases, if the Dean, AP has approved their application, additional makeup sessions may be provided to the concerned students.
- If a case of plagiarism/copying is detected in the exams or lab submissions (IT112/IT113), that student will receive zero marks in the complete lab segment or the respective exam component. The student will also be reported to the Dean, AP for further actions.
