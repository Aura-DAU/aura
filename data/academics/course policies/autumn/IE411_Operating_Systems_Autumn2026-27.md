## Course Description

This elective course builds upon the UG computer systems programming course that introduces the basic OS abstractions at the level of system calls. It provides a comprehensive understanding of the mechanisms underlying the basic OS abstractions, including their implementations.

**Topics to be covered:**
- Multi-programming: processes and threads, context switching, scheduling metrics, scheduling policies, MLFQ scheduler, O(1) scheduler, Completely Fair Scheduler, multi-processor scheduling
- Concurrency and synchronization: race conditions, critical sections, mutual exclusion, Peterson's algorithm, hardware support for locking, spin lock, ticket lock, blocking lock, semaphores, condition variables, implementation issues, deadlocks, lock-free data structures
- Virtual memory: logical/physical address spaces, paging, protection, TLB, demand paging, copy-on-write, page replacement policies, implementation issues
- File systems: hard-disk drives, device drivers, files and directories, hard links, symbolic links, file system implementation, i-nodes, file layout approaches, crash recovery, journaling, RAID, fast file system, solid-state drives, file systems for SSDs
