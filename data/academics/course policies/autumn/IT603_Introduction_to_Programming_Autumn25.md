## Course Description

The course is designed as a first-timer introduction to programming. It assumes no prior exposure to programming. The course aims at imparting students a solid understanding of not only programming language features but also fundamental knowledge that is transferable to other languages as well.

---

## Course Outcomes (COs)

After taking this course, students will be able to write portable, efficient application programs in C++. They will also be able to navigate Linux environments fluently and take up new programming languages with relative ease.

## Course Structure

| Unit | Topic |
|---|---|
| 1 | Introduction to Linux environment — Computer system, Shell, Command line Interface, Standard I/O, System Path |
| 2 | Introduction to Programming — Introduction to Modern C++, concept of program flow, why modern C++ without OOP is C, Hello world, Program structure, Compilation process |
| 3 | Data types and Concept of Variables — Data types, Variable, Static variables, global variables |
| 4 | Program Control — Logical operators, bitwise operators, functions, Conditional constructs |
| 5 | Array, Pointers, Structures — Arrays, pointers, array of characters, multi-dimensional arrays, pointers to functions, structures and classes |
| 6 | Dynamic Memory Allocation — creating variables on the free-store, memory management |
| 7 | Modern C++: Templates — Generic programming, Template structure and definition |
| 8 | Modern C++: STL — std::string, STL algorithms |
