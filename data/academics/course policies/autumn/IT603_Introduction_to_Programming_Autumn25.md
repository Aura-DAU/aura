## Course Description

This course aims to build a strong foundation in object-oriented programming using C++. The course begins with programming paradigms and fundamental programming concepts such as basic data types, expressions, control structures, and arrays and gradually introduces essential object-oriented concepts such as classes, objects, encapsulation, constructors, destructors, inheritance, and polymorphism. The course also introduces modern C++ concepts, including generic programming through templates and the Standard Template Library (STL). The course aims at imparting students a solid understanding of not only programming language features but also fundamental knowledge that is transferable to other languages also.

## Course Structure

*Detailed Course Content (Module-wise), Total 36 Lectures. Note (as stated in source): "This course plan is subject to change without notice."*

| Unit | Topic | No. of Lectures |
|---|---|---|
| Module 1 | Introduction to the Linux (Ubuntu) Programming Environment: Linux File System, Command Line Interface, Essential Linux Commands, Shell and Bash, Environment Variables, System PATH, Working with Text Files and Editors (nano/vi) | 3 |
| Module 2 | Introduction to Programming Paradigms (procedural and object-oriented), Structure of a C++ program, C++ program compilation (GCC/G++ Compilation Process), Debugging using GDB, Multi-file Programs, Makefiles, and Introduction to Git and Version Control | 4 |
| Module 3 | C++ Data types, Variables, Constants, Expressions, Namespaces, Control Structure, Array, and String | 4 |
| Module 4 | C++ Functions: Function Declaration and Definition, Pass-by-value, pass-by-reference, Default arguments, Inline Functions, scope and storage classes, static data and static function, Recursion, Pointers in C++, Dynamic memory: new and Delete Operators | 5 |
| Module 5 | C++: Classes and Objects — Introduction to Object-Oriented Programming. Encapsulation, abstraction, Class structure, Access control, Constructors/Destructors in C++: Multiple constructor, Parametrized constructor, Copy constructor, Destructor | 5 |
| Module 6 | Operator overloading and type conversion: Unary Operator Overloading, Binary Operator Overloading, Operator Overloading using Friend Functions, Implicit Type Conversion, Explicit Type Conversion | 2 |
| Module 7 | Inheritance and polymorphism: Types of inheritance, Base/derived classes, Access control & constructors, and destructor invocation order. Introduction to polymorphism, pointer to object, Early Binding and Late Binding, virtual function, pure virtual function, Virtual Destructors, Abstract class | 5 |
| Module 8 | Templates and Generic Programming: introduction to Generic Programming, Function Templates, Class Templates | 2 |
| Module 9 | Introduction to STL: Containers (vector, lists, Stacks, Queues, Deque, Sets, Maps), Iterators and Algorithms, lambda expressions | 2 |
| Module 10 | Exception Handling: Introduction, Cause of Run-Time Errors, Exception Handling Mechanism in C++, Try, Catch, Throw, Blocks, Multiple Catch Blocks | 2 |
| Module 11 | File Streams: ifstream, ofstream, fstream, processing of Text Files and Binary Files, Command-Line Arguments | 2 |
| **Total** | | **36** |
