## Course Outcomes (COs)

| CO | Description |
|---|---|
| CO1 | Algorithmic Knowledge: Understand fundamental algorithms, including sorting, searching, and graph algorithms. |
| CO2 | Algorithm Design Skills: Apply techniques like divide and conquer, dynamic programming, and greedy algorithms to solve computational problems. |
| CO3 | Complexity Analysis: Analyze algorithms using Big-O notation to determine time and space complexity. |
| CO4 | Problem-Solving Proficiency: Develop skills in solving algorithmic problems through logical and structured thinking. |
| CO5 | Implementation Ability: Implement algorithms in programming assignments to translate theoretical concepts into practical solutions. |
| CO6 | Critical Thinking: Evaluate and compare different algorithms based on their theoretical analysis and practical performance. |

## Course Structure

| Unit | Topic |
|---|---|
| 1 | Notions of problems and algorithms, analysis and asymptotic notation |
| 2 | Paradigms of iterative, divide & conquer, greedy algorithms and dynamic programming (covered via problems and algorithms) |
| 3 | Sorting algorithms (insertion, selection, bubble, merge, quick, heap) and analysis; counting sort, radix sort |
| 4 | Searching: linear search, binary search, ranks in linear lists |
| 5 | Greedy algorithms: fractional knapsack problem, Huffman codes |
| 6 | Dynamic programming: search-frequency weighted BST, all-pairs shortest paths, matrix chain multiplication, longest common subsequence |
| 7 | Graph algorithms: BFS, DFS, Dijkstra's algorithm for single source shortest paths, minimum spanning trees (Prim's, Kruskal's, and other algorithms), network flows |
| 8 | String matching algorithms: Rabin-Karp algorithm, KMP algorithm |
| 9 | NP-completeness and basics of complexity theory: concepts of reductions, and NP-completeness |
| 10 | Some standard methods of handling NPC problems: approximation algorithms, special cases, heuristics |
