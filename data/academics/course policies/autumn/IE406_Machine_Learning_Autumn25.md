## Course Description

This course introduces the fundamental principles and techniques of Machine Learning with emphasis on both theoretical understanding and practical implementation. The course covers topics such as supervised learning, dimensionality reduction, probabilistic modelling, clustering, and ensemble methods. Students will gain hands-on experience in applying these methods to solve real-world data-driven problems through laboratory assignments and programming exercises.

The course aims to develop mathematical understanding, algorithmic thinking, and practical skills for solving data-driven problems. It emphasizes the core concepts and methodologies that form the basis of modern machine learning systems and prepares students for more advanced topics in machine learning and deep learning.

## Course Structure

| Unit | Topic | No. of Lectures |
|---|---|---|
| Module 1: Linear Regression, Optimization & Generalization | Linear regression, normal closed form solution, convex functions, gradient descent, gradients and sub-gradients, polynomial regression with basis projection expansion, overfitting and underfitting, regularization (L1/L2), Mean Squared Error as MLE and MAP estimates, bias-variance decomposition. Experimental setup: training/testing/validation set, K-fold cross validation, leave-one-out, bootstrap resampling, evaluation metrics for regression (R-squared) | 6 |
| Module 2: Linear Classification Models & Kernel Methods | Perceptron, geometry of decision hyperplane, SVM (hard/soft margin), hinge loss, dual formulation, kernel trick, RBF kernel. Experimental setup: evaluation metrics for classification models, handling class imbalance, stratified cross-validation | 7 |
| Module 3: Probabilistic Classification Models | Probability basics, Bayes theorem, multivariate Gaussian distribution and covariance matrix, logistic regression and its extension to multi-label and multi-class (softmax) classification, generative vs discriminative models, Naive Bayes (LDA and QDA), K Nearest Neighbor classifier, parametric vs non-parametric methods, curse of dimensionality | 7 |
| Module 4: Clustering and Density Estimation | K-means, GMM, Expectation Maximization algorithm | 4 |
| Module 5: Representation Learning & Dimensionality Reduction | Linear basis transformation, intuition of feature manifold, eigenvectors and SVD, PCA, Fischer Discriminant Analysis, metric learning | 6 |
| Module 6: Ensemble Methods | Bagging, Random Forest, Boosting, AdaBoost, feature importance, bias-variance in ensembles, cascaded classifiers | 4 |
| Module 7: Neural Networks & Deep Learning Foundations | Logistic regression as a neural network, need for multiple layers (MLP), activation functions and the need for non-linearity, denoising autoencoder, random weight initialization, automatic gradient computation with computational graphs for backpropagation, advances in gradient descent (momentum, learning rate scheduling), vanishing/exploding gradients problem and residual skip connections, regularization (Dropout, BatchNorm, data augmentation) | 7 |
| **Total** | | **41** |
