## Course Description

**Objective:** Broad topics include discussions on approaches to 3D (object distance from camera) estimation using 2D image pixels, face recognition, and basics of deep learning and its use in high-resolution image generation, image generation from random noise, etc.

**Outcome:** The course would help graduate students understand the basic concepts in computer vision (how the computer can be used to perform the tasks of the human vision system). Through lectures, programming assignments, and presentations, students are provided with the learning experience of:
1. Analysis of images for extracting the 3D coordinates of the object.
2. Developing technical presentation skills.
3. Solving problems that are of an ill-posed nature.
