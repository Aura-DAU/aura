## Course Description

The Internet is the largest engineered system that is being utilized by billions of users through their portable devices, which include laptops, tablets, and smartphones. The inner workings of such a large system with many diverse components and uses need to be understood. This includes the guiding principles and structure that can provide a foundation for understanding such an amazingly large and complex system.

This course will cover the fundamental principles of computer networks with a focus on layered architecture, protocols, implementation, and issues specific to the Internet. The objective is to provide an understanding of how the Internet works, including how data flows from a source to a destination.

The associated laboratory component is designed to expose students to the basic LAN hardware and configuration, and network simulation tools for the analysis of traffic and network protocols.

## Course Structure

| Unit | Topic | No. of Lectures |
|---|---|---|
| 1 | Overview: Overview; Internet — Birds' Eye View, History; Internet — Layered Architecture (OSI and TCP/IP architectures); Packet Switching, Best Effort Services | 6 |
| 2 | Network Applications: Client-Server Applications; Chat Application Design, Socket Programming; SFTP File Transfer Protocol; Domain Name Service, Mail, SMTP; Peer to Peer Search, Distributed Hash; Video Streaming, DASH | 6 |
| 3 | End to End Issues: Transport Layer Basics; Reliability; Connectionless and Connection Oriented Transport; TCP and UDP protocols; Congestion Management; TCP Performance Measure | 6 |
| 4 | Routing and Congestion: Introduction; Scheduling, Best Effort Service; Scheduling for Guaranteed Service, Switching; Packet Switching, Batcher Banyan Switch; Routing — Introduction, Multicast, Broadcast; Addressing, CIDR, IP Protocol IPv4, IPv6; Hierarchical Routing, BGP, Mobile Routing; Control and Data Path, Open Flow; Software Defined Networking | 6 |
| 5 | Link Layer Technologies: Introduction; Media Access Protocols, ALOHA; IEEE 802.3 Ethernet Protocol, MACA; Switched LAN, Virtual LANs | 6 |
| 6 | Wireless Networks: Introduction; IEEE 802.11 MAC protocol; Cellular architecture and Mobility management | 4 |
| 7 (Optional) | Content Distribution Networks: Architecture and protocols; Video Streaming, DASH | 2 |
| 8 (Optional) | Data Center Networks | 2 |
| **Total** | | **38** |

**Lab Outline:**

**A. LAN hardware, Configuration, Network Services**
1. Making LAN cable and setting up a LAN.
2. Multi-LAN communication using a Router. Configuring DHCP and DNS.

**B. Network Simulation on NETSIM** ([documentation link](https://www.tetcos.com/documentation/NetSim/v13/NetSim-Experiments%20Manual/index.htm))
1. Network Performance Measures, Delay, Throughput, Bottleneck Analysis.
2. TCP connection management.
3. TCP performance as a function of error rate, and Round trip time.
4. Wireless LAN with AP and WiFi Performance studies.

**C. Protocol Study and Analysis using Wireshark and Trace files** ([reference link](https://gaia.cs.umass.edu/kurose_ross/wireshark.php))
1. TCP and UDP.
2. DHCP and NAT.
3. SDN based QoS.

**D. Socket Programming**
1. Basic Stream and datagram socket applications.
2. Multi-threaded clients and Server performance as a function of load.

## Additional Notes

**Course Conduct and Grading Policy:**
