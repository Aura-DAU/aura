## Course Description

This course aims to introduce the fundamental concepts of data structures and algorithms using Python, enabling students to develop efficient solutions to computational problems. It focuses on the implementation, analysis, and application of various data structures and algorithmic techniques while enhancing programming, problem-solving, and computational thinking skills.

---

## Course Outcomes (COs)

| CO | Description |
|---|---|
| CO1 | The students will be able to demonstrate proficiency in Python programming constructs and object-oriented concepts relevant to data structures |
| CO2 | The students will be able to analyze the time and space complexity of algorithms using asymptotic notations |
| CO3 | The students will be able to implement and manipulate fundamental linear and non-linear data structures using Python |

## Course Structure

*APPENDIX-I: Detailed Course Content (Session-wise/Module-wise)*

| Unit | Topic | No. of Lectures |
|---|---|---|
| Module 1 | Linear and non-linear data structures, Iteration, Recursion, Problem solving approaches, Algorithm analysis, running time; Python preliminaries | 12 |
| Module 2 | Basic Python practice on Arrays; Lists; Stack; Queue; Sorting and Searching | 15 |
| Module 3 | Basic Python and OOPs approach on Binary Tree; Binary Search Tree; Balanced Tree; Heap; Tree traversals; Graph traversals | 15 |
