## Course Description

The objective of this course is to introduce different classical techniques for machine learning such that students can understand the working principle of different techniques. The course also helps students address different real-life problems with machine learning techniques. Moreover, the project part of the course is devised to encourage students to explore the area of machine learning through research and development.

## Course Structure

| Unit | Topic | No. of Lectures |
|---|---|---|
| 1. Regression | Linear regression; convexity and gradient descent algorithm; vectorization; feature scaling, concept of regularization, normal equation; probabilistic linear regression; ridge regression, the Lasso; basis functions | 11 |
| 2. Resampling - Model Selection | Generalization error; model capacity; cross-validation; the bootstrap; bias-variance decomposition | 4 |
| 3. Classification | Distance-based classification; K-NN, density estimation; Naive Bayes classifier; perceptron; logistic regression, Newton's method, exponential family; softmax; decision tree, ensemble methods; support vector machine and kernel | 14 |
| 4. Clustering | K-means; Gaussian mixture model | 4 |
| 5. Optimal Projection of Data | Principal component analysis; linear discriminant analysis | 4 |
| 6. Neural Networks | Representation; forward propagation; backpropagation | 5 |
| **Total** | | **42** |
