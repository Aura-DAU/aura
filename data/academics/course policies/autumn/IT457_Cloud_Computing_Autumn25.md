## Course Description

Cloud computing systems today, both open source or proprietary, are built using a common set of core techniques, algorithms, and design philosophies, all of which are centered around distributed systems. This course will teach the fundamental concepts of how and why Cloud systems work, as well as Cloud technologies that manifest these concepts, such as from Amazon AWS, Microsoft Azure, and OpenStack. Students will learn concepts like virtualization, containers, orchestration, and performance analysis at scale.

The hands-on component of the course is provided through multiple labs focusing on providing the necessary practical experience of building and deploying applications on cloud infrastructure. For example, this will include learning, installing, and deploying a web application on the Kubernetes platform. The associated laboratory component is designed to expose students to the various aspects of cloud computing.

## Course Structure

| Unit | Topic | No. of Lectures |
|---|---|---|
| I | Introduction to Cloud Computing: Introduction, Historical developments, Building Cloud Computing Environments, Operating systems and networks fundamentals | 6 |
| II | Cloud Computing Architecture: Introduction, Fundamental concepts and models, Cloud Characteristics, Cloud Delivery models, Cloud Deployment models, Economics of the cloud | 6 |
| III | Virtualization: Introduction, Characteristics of virtualized environments, Taxonomy of virtualization techniques, Hypervisor, Containers, Dockers, Pros and cons of virtualization, Technology examples, Cloud Architecture | 8 |
| IV | Principles of Distributed Systems: Elements of distributed systems, Technologies for distributed Computing, Consistency and replication | 4 |
| V | Service Models in Cloud Computing: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), Software as a Service (SaaS), and Metal as a Service (MaaS) | 6 |
| VI | Real World Cloud Computing Technologies: Introduction to OpenStack, Kubernetes, AWS, and Microsoft Azure | 6 |
| VII | Guest lectures and demos from Industry experts | 5–6 |
| **Total** | | **~41–42** |

**Lab Outline:**

| Lab | Description |
|---|---|
| Lab 1: Fundamentals of Networking | Socket programming |
| Lab 2: Introduction to AWS | Walks students through installation and configuration of Virtual Machines on AWS Manager |
| Lab 2 (Continued): VPC Configuration | Introduces the concept of virtual private clouds and their installation on AWS |
| Lab 3: AWS S3 | Introduces Amazon S3; storing/managing data via S3 buckets, versioning, hosting a static website, automating storage management |
| Lab 4: EC2 Instances | Creating EC2 instances and mounting an S3 bucket to experience cloud storage and compute working together |
| Lab 5: AWS SageMaker | Introduces a tool for training and deploying ML models |
| Lab 6: Kubernetes | Introduces containers and automatic orchestration principles using Kubernetes |
| Lab 7: Serverless Computing | Introduces serverless computing; implementing a simple AWS Lambda function via AWS Management Console; also introduces AWS CloudWatch for observing/debugging serverless applications |

*Note: The source document numbers two labs both as "Lab 2" (Introduction to AWS, and VPC Configuration) — this numbering duplication is preserved as it appears in the source.*
