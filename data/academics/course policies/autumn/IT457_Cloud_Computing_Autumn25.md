## Course Description

Cloud computing systems today, both open-source and proprietary, are built using a common set of core techniques centered around distributed systems. However, modern cloud engineering has evolved past basic infrastructure deployment toward tight cost governance, automated lifecycle management, and developer-centric platform abstractions.

This course teaches the fundamental concepts of how and why Cloud systems work, spanning hyperscalers like Amazon AWS and Microsoft Azure, alongside open-source frameworks like OpenStack and the CNCF ecosystem. Students will master foundational concepts like virtualization and containers, while quickly advancing into current operational paradigms including Platform Engineering, Cloud Cost Optimization, DevOps, and Multi-Cloud Sovereignty architectures.

## Additional Notes

**Lab Plan (Tentative, as stated in source):**
- Lab 1: Fundamentals of Networking - Socket programming.
- Lab 2: Introduction to AWS - installation and configuration of Virtual Machines on AWS Manager.
- Lab 2 (as numbered in source): VPC Configuration - introduces the concept of virtual private clouds and their installation on AWS.
- Lab 3: AWS S3 - introduces the concept of Amazon S3; students learn to store and manage data by creating S3 buckets, protect data using features like versioning, host a static website directly from an S3 bucket, and automate storage management.
- Lab 4: EC2 Instances - introduces how to create EC2 instances and mount an S3 bucket on it to experience how cloud storage and compute can work together seamlessly.
- Lab 5: Kubernetes - introduces containers and automatic orchestration principles using Kubernetes.
- Lab 6: Serverless computing - introduces the concepts of serverless computing and implementing a simple AWS Lambda function using the AWS Management Console; also introduces AWS CloudWatch for observing and debugging serverless applications.

*Note: The source document numbers two consecutive labs as "Lab 2" (Introduction to AWS, and VPC Configuration); this has been reproduced as it appears in the source.*
