## Course Description

Digital logic and computer organization provide the foundation for understanding modern computing systems, processor architecture, and program execution. The course begins with the principles of digital logic, introducing Boolean algebra, switching theory, and the design of combinational and sequential circuits. Students learn how logical operations are implemented in computers, developing the ability to derive Boolean expressions, design and analyze digital logic, evaluate timing behavior, and implement processor-oriented solutions.

Building on these concepts, the course explores computer organization, bridging the gap between digital building blocks and programmable computing systems. Students examine the internal structure of computer systems, including processor datapath design, instruction execution, memory hierarchy, and input/output mechanisms. The course emphasizes how machine-level operations are realized using digital hardware and how architectural design decisions influence system functionality and performance.

By the end of the course, students will have a comprehensive understanding of the relationship between digital logic, processor architecture, and computer organization, enabling them to analyze, design, and evaluate the hardware systems that underpin modern computing.

## Course Structure

| Unit | Topic | No. of Lectures |
|---|---|---|
| 1 | Boolean Logic: Boolean algebra, canonical expressions, minterms, maxterms, Karnaugh maps, logic minimization | 7 |
| 2 | Combinational Logic: logic gates, buffers, multiplexers, decoders, encoders, arithmetic circuits and blocks | 7 |
| 3 | Sequential Logic: latches, flip-flops, registers, timing diagrams, FSM design, logic blocks modelling and design concepts | 7 |
| 4 | Instruction Set Architecture: instruction formats, addressing modes, instruction execution cycle, basic assembly concepts | 7 |
| 5 | Processor Organization: datapath design, control units, single-cycle and multi-cycle processors, pipelining | 7 |
| 6 | Memory and I/O Systems: memory hierarchy, cache concepts, memory controllers, interrupts and I/O mechanisms | 7 |
| **Total** | | **42** |
