## Course Description

This course provides an introduction to computer organization, assembly language programming, and high-level language programming using C. Topics include the memory unit, arithmetic and logic unit, control unit, addressing modes and instructions for assembly language programming, along with C programming which covers data types, conditions and loops, arrays, functions, structures, unions, and pointers.

---

## Course Outcomes (COs)

At the end of the course, students will be able to:

| CO | Description |
|---|---|
| CO1 | Design instruction set architecture. |
| CO2 | Apply the concepts of digital logic to design the basic building blocks of a computer. |
| CO3 | Understand the internal architecture of the CPU, memory hierarchy, assembly language instructions and addressing modes, and timing analysis of instructions. |
| CO4 | Write efficient C programs and analyze them to improve the space and time complexity. |

## Course Structure

| Unit | Topic |
|---|---|
| 1 | Computer Organization: Components of computer, memory unit, computation unit, control unit, input/output unit, Bits, data types, operation, logic structures, Von Neumann model, language |
| 2 | Assembly Language Programming: Basic Syntax, Memory Segments, Registers, System Calls, Addressing Modes, Variables, Constants, Arithmetic and logical Instructions, Conditions and Loops, Numbers, strings and arrays |
| 3 | C Programming: Brief Overview, Basic Syntax, Program Structure, Data Types, Variables, Constant, Conditions and Loops, Arrays, Function, Pointers, Structures and Unions |
