## Course Description

Machine Learning is a growing field in the area of pattern recognition, natural language processing, speech processing, image processing, computer vision, etc. This course covers topics in classical machine learning and, if time permits, introduces neural networks for deep learning.

**Objectives:**
1. Formulate machine learning problems related to different applications and develop algorithms to solve them.
2. Read current research papers and understand the issues.

This course has both Theory and Lab components. Labs are based on the theory taught in class.

---

## Course Outcomes (COs)

**Expected Outcomes:** After studying this course, students will be able to understand a variety of machine learning architectures, and use them to solve problems in object classification and segmentation (clustering). The course will be helpful for students to come up with new research ideas in various application areas of machine learning.

## Course Structure

## Evaluation / Grading Scheme

| Component | Weightage |
|---|---|
| Lab | 5% |
| Class Participation (reward points for answering questions asked during class hours, max 10 points) | 10% |
| Midsem Exam and Endsem Exam (best of the two considered) | 40% |
| Course Project | 45% |
| **Total** | **100%** |

*Note: Performance is evaluated based on a continuous evaluation process that includes project, lab, class participation, one Mid-semester Examination, and an End-Semester Examination. TAs will also be part of the evaluation process.*

**Course Project Presentations:** Two presentations in a semester — at the beginning and towards the end. In a project group, a person randomly chosen will present on a prescribed date (decided by the Instructor). The marks obtained by that student will be awarded to all students in that group. Codes are to be verified by TAs.
