## Course Description

This course teaches the use of Relational Database Management Systems (RDBMS) to understand and solve a wide range of information storage and query processing problems in organizations ranging from large corporations to personal applications. The course combines the practical aspects of DBMS use with basic theory discussions about database design. Students will be learning basic storage and query processing concepts of Parallel and Distributed Databases. As part of the lab assignments/a project, students will learn to build and query the database using a DBMS tool for the given problem domain (case study).

---

## Course Outcomes (COs)

The students will learn to store data and process queries using the RDBMS data model. A database will be designed and implemented using relational technology.

## Course Structure

| Unit | Topic | No. of Lectures |
|---|---|---|
| 1 | Course Overview: Basic Definitions, Data Storage, Queries, Transaction Management | 2 |
| 2 | Relational Model: Introduction, Integrity Constraints, Logical Database Design | 4 |
| 3 | Query Language: SQL | 4 |
| 4 | Requirements Collection and Analysis; Data Models: E-R Model, Conceptual Design | 4 |
| 5 | Database Design & Tuning: Functional Dependency, Normal Forms, Decomposition, Normalization, Schema Refinement | 5 |
| 6 | Data Storage: Physical Storage, Hierarchy, Data Storage Structures, Indexing Techniques | 4 |
| 7 | Query Processing and Optimization: Query Cost, Evaluation Plans, Materialized Views | 4 |
| 8 | Transaction Management: ACID properties, Transactions as SQL Statements; Concurrency Control: Lock based, Time stamp based, Validation based, Deadlock detection and handling, Multiversion, Multigranularity | 4 |
| 9 | Distributed and Parallel Databases: Data Storage and Query Processing | 4 |
| 10 | Modern Databases: NoSQL Databases, Columnar Storage | 4 |
