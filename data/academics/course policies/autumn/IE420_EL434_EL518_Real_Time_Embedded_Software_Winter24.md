## Course Description

This course introduces the design and implementation of real-time embedded software systems with strict response-time requirements. It covers embedded hardware, real-time operating systems (RTOS), driver configuration, sensor interfacing, and real-time data streaming to cloud-based platforms. Through lectures and hands-on labs, students develop systems used in applications such as healthcare monitoring, smart infrastructure, IoT, and edge computing.

## Course Structure
