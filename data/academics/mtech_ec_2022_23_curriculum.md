# M.Tech Electronics & Communication (EC) – Complete 2022-23 Curriculum

## Program Identity

- **Full Name:** Master of Technology (Electronics and Communications) with Specialization in Wireless Communication and Embedded Systems
- **Short Name:** M.Tech (EC)
- **Offered by:** DA-IICT, Gandhinagar jointly with CR Rao AIMSCS, Hyderabad
- **Duration:** 2 years (4 semesters) full-time
- **Effective From:** 2022-23 batch
- **Total Credits Required:** 58 (minimum)
- **CPI for Graduation:** 6.0

> **Important for Retrieval:** This is the M.Tech EC curriculum. It is DISTINCT from M.Tech ICT. EC focuses on Wireless Communication and Embedded Systems; ICT covers Software Systems, Machine Learning, and VLSI & Embedded Systems specializations.

## Semester-Wise Course Structure

### Semester I (Total: 15 Credits)

| Course Type | Description | Credits |
|---|---|---|
| Program Core-I | Communication Skills and Technical Writing | 2 |
| Program Core-II | Programming Lab | 3 |
| Specialization Core-I (EC) | One EC-specific core course | 4 |
| General Elective-I | One course from designated Mathematics basket | 3 |
| General Elective-II | One course from designated Technical basket | 3 |

**Semester I Total: 15 credits**

### Semester II (Total: 14 Credits)

| Course Type | Description | Credits |
|---|---|---|
| Specialization Core-II (EC) | One EC-specific core course | 4 |
| Specialization Elective-I | EC-domain elective | 3–4 |
| Specialization Elective-II | EC-domain elective | 3–4 |
| Minor Project-I | Supervised project under faculty mentor | 3 |

**Semester II Total: 14 credits**

### Summer Semester (Total: 4 Credits)

| Course Type | Description | Credits |
|---|---|---|
| Major Project-I | Preliminary supervised research/project work (0-0-8-4) | 4 |

**Summer Total: 4 credits**

### Semester III (Total: 13 Credits)

| Course Type | Description | Credits |
|---|---|---|
| Specialization Elective-III | EC-domain elective | 3–4 |
| Specialization Elective-IV | EC-domain elective | 3–4 |
| Major Project-I (continuation) | Continuation of Summer Major Project-I (0-0-12-6) | 6 |

**Semester III Total: 13 credits**

### Semester IV (Total: 12 Credits)

| Course Type | Description | Credits |
|---|---|---|

**Semester IV Total: 12 credits**

> Note: If the student chooses Major Project-II, it must be a continuation of Major Project-I. Successful completion earns a thesis certificate.

## EC Specialization Core Courses

The two Specialization Core courses (Sem I and Sem II) are specific to the EC program's Wireless Communication and Embedded Systems specialization. Representative core courses include topics in:
- Digital Communications / Wireless Communications
- Embedded Systems Design
- Signal Processing fundamentals relevant to EC

## Representative EC Specialization Electives

EC-specific elective courses are drawn from the following domain areas:
- Advanced Wireless Communications (CT548)
- Adaptive Signal Processing (CT502)
- Detection and Estimation Theory (CT505)
- Advanced Digital Signal Processing (CT421)
- Satellite Technology and Applications (CT474)
- Microwave Engineering (CT476)
- Wavelet Signal Processing (CT423)

## General Elective Baskets (EC Students)

**Mathematics Basket (choose one):**
- Probability & Random Variables
- Linear Algebra
- Optimization
- Graph Theory
- Or any other relevant mathematics course

**Technical Basket (choose one):**
- Machine Learning
- Digital Image Processing
- IoT
- Or any other relevant technical course

## Maximum Duration

- Regular students: 3 years (6 semesters)
- Sponsored category: 4 years (8 semesters)

## Key Distinction from M.Tech ICT

| Feature | M.Tech EC | M.Tech ICT |
|---|---|---|
| Offered jointly with | CR Rao AIMSCS, Hyderabad | DA-IICT only |
| Specialization | Wireless Communication & Embedded Systems | Software Systems / Machine Learning / VLSI & Embedded |
| Core courses | EC-domain (communications, signal processing, embedded) | ICT-domain (algorithms, software engineering, ML, VLSI) |
| Total credits | 58 | 58 |
| Program structure | Identical semester framework | Identical semester framework |
