| Course
Objectives/
Brief Course
Description | The world is increasingly relying on data collection/analysis for the decision
making process. Presently, an enormous amount of data gets generated every
day. However, human beings have relatively constant perceptual and cognitive
abilities. It is always difficult or almost impossible to notice mistakes within
a dataset and that makes data visualization particularly important. Data
visualization provides a powerful way to communicate data-driven findings
and motivate interesting analyses. Effective visual encoding can supplement
cognitive calculations with simple perceptual inferences and improve
comprehension and decision making process. Good visual representations
help engaging more diverse audiences in the process of analytic thinking.
In this course, students will learn the foundations of information visualization
and design. Lab assignments using Tableau will sharpen their skills in
communicating using data. Goal of the course is to explore the important
concepts in human perception, decision-making, color theory, and storytelling
as the students get hands-on-experience while applying the concepts in lab
assignments / course-project.
Short assignments will help students get comfortable with the various
techniques we discuss during lectures. The assignments will be done using a
real-dataset. Project will give an opportunity to students to apply visualization
to a dataset of their choosing. |  |  |

APPENDIX: Detailed Course Content (Module-wise)

| Module 1 | Introduction to Data Visualization and Getting Started with Tableau, what
and why, perception and cognition, |
|---|---|
| Module 2 | Data Abstraction - Data types, Dataset Types (Tables, fields etc), Attribute
Types (Categorical, Ordered etc), Semantics |
| Module 3 | Task abstraction - Actions and Targets, Analyzing and Deriving |
| Module 4 | Marks and Channels - Using Marks and Channels, Visual Channels and
encoding, and Channel Effectiveness. |
| Module 5 | Arrangements by Keys and Values, Express Quantitative Values,
Separate, Order, Align, Spatial Axis Orientation, Spatial Layout Density. |
| Module 6 | Arrange Spatial fields - Geometry, Geographic Data, Scalar Fields, Vector
Fields. |
| Module 7 | Colors - Theory, HSL, colormaps, categorical vs ordered color, color
palettes, color deficiency. |
| Module 8 | Manipulate View: Change View over Time, Select Elements, Navigate-
facet into Multiple Views. Reduce Items and Attributes, hierarchical and
multivariate data. |
| Module 9 | Data visualization choices, design principles, presentation and storytelling
techniques using multiple visualization idioms such as Scatterplot, bar and
line chart, streamgraph, stacked bar chart, Gantt charts, slope graphs,
heatmap, histogram, box-plot, radar plot, pie and coxcomb chart, Sankey
diagram, ridgeline plot, radar plot, glyph maps, SPLOM, parallel |
