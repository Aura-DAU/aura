# EL203 EmbeddedHardwareDesign Winter26

## Main Content

| Course Title | Embedded Hardware Design |  |  |
|---|---|---|---|
| Course Code | EL203 | Credit Structure | 3-0-2-4 (L-T-P-C) |
| Category | Core | Semester | Winter Semester (AY 25-26) |
| Program | B.Tech. (ICT, CS, EnV) |  |  |
| Prerequisites | Digital Logic and Computer Organization |  |  |
| Course Objectives/ Brief Course Description | This course will give the students an introductory understanding of embedded systems which includes the programming the AVR microcontroller/ARM processor based Microcontrollers, VHDL, Hardware/Software Co-Design, interfacing of external peripheral devices to microcontroller, and troubleshooting the embedded systems (PO1, PO3, PSO1). The course consists of two parts which are (i) interactive lecture section and (ii) hand-on which will provide a platform to develop an embedded system from scratch (PO11, PEO1, PEO2). Students will gain knowledge on embedded system functions, embedded components, embedded software, and coding which are required for practical implementation of a real embedded system (PO5, PO9, PSO2, PEO5). Students will acquire skills on embedded system coding, microcontrollers, sensors, and actuators to become a good embedded system engineer (PSO2, PEO3). Today, world leading companies are looking for the people who are expertise in the areas of embedded systems, embedded AI, and edge computing, etc (PO10, PO11). This course will provide a platform to develop skills for which companies are interested to hire professionals (PO6). |  |  |
| Evaluation/ Grading Policy | Two in-semester examinations, a final examination, and lab assignments. Evaluation scheme: (i) First In-Sem Exam: 20%, (ii) Second In-Sem Exam: 20%, (iii) End-Sem Exam: 30%, and (iv) Labs: 30%. |  |  |
| Course Materials/ References | Text Book: Frank Vahid and Tony Givargis, Embedded System Design: A Unified Hardware/Software Introduction, Wiley, Student edition, 2006. Reference Book: 1) Sarah Harris and David Harris, Digital Design and Computer Architecture: ARM Edition, Morgan Kaufmann Publishers Inc., United States, May 2015. 2) Jonathan Walker Valvano, Embedded Systems: Introduction to Arm® Cortex™-M Microcontrollers, 5th Edition, CreateSpace Independent Publishing Platform, 2011. 3) Samir Palnitkar, Digital Design using Verilog HDL, Prentice Hall; 2nd Edition, 2003. 4) ARM System Developer’s Guide: Designing and Optimizing System Software 1st Edition (Designing and Optimizing System Software) Publisher: Morgan Kaufmann Publishers Inc., 2011. |  |  |
