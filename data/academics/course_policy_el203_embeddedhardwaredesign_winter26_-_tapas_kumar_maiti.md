### Course Description  
This course provides introductory understanding of embedded systems including:  
- Programming AVR microcontroller/ARM processor based Microcontrollers  
- VHDL and Hardware/Software Co-Design  
- Interfacing external peripheral devices  
- Troubleshooting embedded systems  

The course combines:  
1. Interactive lecture section  
2. Hands-on development of embedded systems from scratch  

### Learning Outcomes  
Students will gain:  
- Knowledge of embedded system functions, components, software, and coding  
- Skills in embedded system coding, microcontrollers, sensors, and actuators  
- Preparation for careers in embedded systems, embedded AI, and edge computing
