# EL203 Embedded Hardware Design Winter26

## Course Details

### Course Information

* Course Title: Embedded Hardware Design
* Course Code: EL203
* Credit Structure: 3-0-2-4 (L-T-P-C)
* Category: Core
* Semester: Winter Semester (AY 25-26)
* Program: B.Tech. (ICT, CS, EnV)
* Prerequisites: Digital Logic and Computer Organization

### Course Objectives and Brief Course Description

This course will give the students an introductory understanding of embedded systems which includes the programming the AVR microcontroller/ARM processor based Microcontrollers, VHDL, Hardware/Software Co-Design, interfacing of external peripheral devices to microcontroller, and troubleshooting the embedded systems (PO1, PO3, PSO1). The course consists of two parts which are (i) interactive lecture section and (ii) hand-on which will provide a platform to develop an embedded system from scratch (PO11, PEO1, PEO2). Students will gain knowledge on embedded system functions, embedded components, embedded software, and coding which are required for practical implementation of a real embedded system (PO5, PO9, PSO2, PEO5). Students will acquire skills on embedded system coding, microcontrollers, sensors, and actuators to become a good embedded system engineer (PSO2, PEO3). Today, world leading companies are looking for the people who are expertise in the areas of embedded systems, embedded AI, and edge computing, etc (PO10, PO11). This course will provide a platform to develop skills for which companies are interested to hire professionals (PO6).

## Detailed Course Content

### Module-1: Introduction

* Embedded Systems Overview
* Design Challenges – Optimizing Design Metrics
* Processor and IC Technologies
* Design Technology and Trade-offs

### Module-2: Custom Single-Purpose Processors

* Binary Information Implemented with MOS transistors
* Digital Logic, Logic gates
* Combinational and Sequential Logic
* RT-Level Combinational and Sequential Components
* Basic Computer Architecture
* Finite State Machines (FSM)
* Optimizing Datapath
* Hardware Description Languages: Verilog HDL
* Field Programmable Gate Array (FPGA)

### Module-3: Microcontroller Based on Cortex-M Class Processors/AVR microcontroller

* AVR microcontroller, ARM/Cortex family microcontrollers
* AVR microcontroller, ARM Assembly Language
* Introduction to Embedded C
* Mixing C and Assembly
* Developing programs with ARM/Cortex microcontrollers
* Peripheral Drivers Development
* Introduction to Keil µVision

### Module-4: Real-Time Interfacing

* Introduction to Input/Output
* SysTick Timer
* ARM interrupts and interrupt processing
* GPIO Polling and Interrupt
* UART-Serial Interface
* Analog I/O Interfacing, I/O Synchronization, RS232, I2C, CAN
* USB Protocols, Bluetooth

### Module-5: Implementation of Embedded Systems

* Open-Loop and Closed-Loop Control Systems
* Example: Self-Driving Car
* ADC and DAC
* IMU (Inertial Measurement Unit), Image Sensor, Pressure Sensor
* Servo-Motor, Pulse-Width-Modulation (PWM)
* Proportional-Integral-Derivative (PID) Controller
* Integration of Sensors and Motors with RaspberryPi/Arduino Boards

### Module-6: Memory

* Introduction
* Common Memory Types, ROM, RAM, EEPROM, SRAM
* Memory Hierarchy and Cache
* Advanced RAM, DRAM
* Memory Management

### Module-7: IC Technology

* Full-Custom IC Technology
* Semi-Custom IC Technology
* Programmable Logic Device IC Technology
* Design Technology: Automation and Synthesis
* Verification: Hardware/Software Co-Simulation
