## Course Description
The Machine Learning System Engineering course covers the complete ML system lifecycle and MLOps in production environments. Students learn object-oriented Python, Git/GitHub workflows, data acquisition, and ethical considerations. A significant focus is placed on containerization using Docker and managing scalable ML workloads on Kubernetes. The curriculum also explores orchestrating data pipelines (Apache Airflow/Luigi), building RESTful APIs, and utilizing cloud ML platforms. Ultimately, students integrate security, CI/CD, and industry best practices into an end-to-end corporate-style ML capstone project.

## Textbooks and References
1. **Designing Machine Learning Systems** – Chip Huyen
   - *Why*: Practical book on building and deploying ML systems at scale. Covers ML lifecycle, MLOps, data pipelines, experimentation, deployment, and monitoring in industry settings.
   - *Industry Relevance*: Written from a product and engineering perspective, with case studies from leading tech companies.
2. **Kubernetes for Machine Learning** – Emmanuel Raj
   - *Why*: Hands-on approach to running, scaling, and managing ML workloads with Kubernetes. Includes examples with Docker, Kubeflow, and cloud platforms.
   - *Industry Relevance*: Perfect for bridging the gap between data science and production infrastructure.
