# M.Tech ICT (2022-23) Curriculum Change Log

## Versions Compared

| Version | Effective From | Document |
|---|---|---|
| **New** | 2022-23 batch | M.Tech (ICT) Program wef 2022-23 |
| **Previous** | 2021-22 batch | M.Tech (CS&ML) – Communication Systems & Machine Learning, wef 2021-22 |

> **Note:** The 2021-22 M.Tech offering was named "M.Tech (CS&ML)" – Master of Technology in Communication Systems and Machine Learning, jointly offered by DA-IICT and CR Rao AIMSCS. The 2022-23 restructuring introduced the broader **M.Tech (ICT)** brand with multiple specializations exclusively under DA-IICT, replacing the more narrowly defined CS&ML program.

## Summary of Major Changes

### Added in 2022-23

| Addition | Details |
|---|---|
| **New Specializations** | Software Systems and VLSI & Embedded Systems added as two new ICT specializations (Machine Learning was retained) |
| **M.Tech (ICT) brand** | Program renamed from M.Tech (CS&ML) to M.Tech (ICT) to reflect broader ICT coverage |
| **Software Systems Specialization** | Core courses: Advanced Algorithm (Sem I), Advanced Software Engineering (Sem II); Electives: Distributed Systems, Distributed Databases, Big Data Processing, Blockchains, Advanced Networks, etc. |
| **VLSI & Embedded Systems Specialization** | Core courses: VLSI System Design (Sem I), Embedded Hardware Design (Sem II); Electives: ASIC Design, Analog VLSI, Digital System Architecture, VLSI Testing, Nanoelectronics, etc. |
| **Exclusive DA-IICT offering** | M.Tech (ICT) is offered solely by DA-IICT (no joint offering); the CS&ML was joint with CR Rao AIMSCS |

### Retained (Unchanged) in 2022-23

| Feature | Details |
|---|---|
| Machine Learning specialization | Retained with same core courses (Foundations of ML, Advanced ML) and similar elective basket |
| Total credits | 58 credits (33 coursework + 25 project) – unchanged |
| Credit structure | 13 compulsory + 20 elective credits – unchanged |
| Semester structure | 4 semesters + Summer (identical framework) – unchanged |
| Program Core courses | Communication Skills & Technical Writing (2 cr) + Programming Lab (3 cr) – unchanged |
| Minor Project (Sem II) | 3 credits – unchanged |
| Major Project I summer | 4 credits – unchanged |
| Major Project I continuation (Sem III) | 6 credits – unchanged |
| Major Project II / Industrial Training (Sem IV) | 12 credits – unchanged |
| CPI for graduation | 6.0 – unchanged |
| Maximum duration | 3 years (6 semesters) regular; 4 years (8 semesters) sponsored – unchanged |

### Removed / Changed in 2022-23

| Removal / Change | Details |
|---|---|
| **CS&ML joint program with CR Rao AIMSCS** | The M.Tech (CS&ML) joint program with CR Rao AIMSCS has been replaced by the standalone M.Tech (ICT) |
| **Communication Systems as a standalone track** | The 2021-22 CS&ML had Wireless Communication as the domain; in 2022-23, a separate M.Tech (EC) is offered jointly with CR Rao AIMSCS for this track |
| **Program naming** | "CS&ML" (Communication Systems and Machine Learning) → "ICT" (Information and Communication Technology) with specializations |

## Detailed Specialization Comparison

### Machine Learning Specialization (Retained in ICT 2022-23)

| Element | CS&ML 2021-22 | ICT 2022-23 (ML Specialization) |
|---|---|---|
| Sem I Core | Foundations of Machine Learning | Foundations of Machine Learning ✓ |
| Sem II Core | Advanced Machine Learning | Advanced Machine Learning ✓ |
| General Electives | Math + Technical basket | Math + Technical basket ✓ |
| Elective examples | Deep Learning, Computer Vision, NLP, RL, Speech Tech | Deep Learning, CV, NLP, RL, etc. ✓ |

### New Specializations in ICT 2022-23 (Not in CS&ML 2021-22)

- **Software Systems:** Advanced Algorithm + Advanced Software Engineering as cores; Distributed Systems, Big Data, Blockchains, Advanced Networks as electives.
- **VLSI & Embedded Systems:** VLSI System Design + Embedded Hardware Design as cores; ASIC Design, VLSI Testing, Nanoelectronics as electives.

## Key Structural Shift

The primary change in 2022-23 is the **expansion from a single dual-institution program (CS&ML with CR Rao AIMSCS) to a multi-specialization program (ICT) run exclusively by DA-IICT**, while the EC track (Wireless Communication + Embedded Systems) was separated into its own standalone M.Tech (EC) degree jointly with CR Rao AIMSCS.
