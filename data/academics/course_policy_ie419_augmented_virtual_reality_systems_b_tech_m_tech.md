## Course Description
The course intends to build foundation in the area of Extended Reality, covering virtual, augmented and mixed reality. The topics to be covered include introduction to the field, the hardware and software used to build and deploy such systems, understanding and implementing the immersive experience and finally, hands-on exercises to design, build and deploy XR systems.

## Course Structure

| IE419 Unit | Topic | No. of Lectures |
|---|---|---|
| Introduction | General introduction to the area; historical evolution; application overview | 5-6 |
| XR Hardware & Software | Overview of XR hardware including input and output devices; XR software overview including ideas on game engines and SDKs. | 5-6 |
| Creating XR Experience: Design | XR as interactive systems; Human factors; Interaction techniques for immersive experience | 10-12 |
| Creating XR Experience: Implementation | Interactive system development life cycle; Basics of 3d rendering pipeline; Object detection & tracking fundamentals | 10-12 |
| Putting everything together | Practical sessions: building of an AR and a VR system, using Unity game engine, Google VR and Wikitude SDKs. Will cover the installation of software, coding & deployment. | 10-12 |

## Textbooks and References
There will be no fixed text book. The instructor will cover materials from multiple books, research papers and on-line resources. At the end of each lecture, the source material to read from will be mentioned. The following are few of the reference materials:

1. LaValle, S. M. (2023). Virtual Reality. Cambridge University Press. (available online)
2. Gerald, J. (2015). The VR Book: Human-Centered Design for Virtual Reality. ACM and & Morgan & Claypool Publishers.
3. Bhattacharya, S. (2015). Computer Graphics. Oxford University Press.
4. Bhattacharya, S. (2019). Human-Computer Interaction: User-Centric Computing for Design. McGraw-Hill India.
