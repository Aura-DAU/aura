## Detailed Course Content

APPENDIX A: Lectures/Modules APPENDIX B: Lab Experiments Course Outcomes: • CO1: Understand the representation of data using number systems and binary codes. • CO2: Apply Boolean algebra and simplification techniques to design logic circuits. • CO3: Design and implement combinational logic circuits using basic gates and ICs. • CO4: Analyze and build sequential logic systems like flip-flops, counters, and registers. • CO5: Use digital ICs and breadboard setups to verify logical functions through lab experiments. Implement one's complement of a 4-bit number A when control input C=1, else leave A unchanged. Lab 2: Binary Arithmetic and Binary Codes Implement half adder and half subtractor. Design a 4-bit binary to Gray code converter and even parity generator. Lab 3: Four-bit Increment and Decrement Circuits Implement 4-bit decrementer with control input. Derive expression and design for 4-bit increment-by-2 circuit. Lab 4: Universal Logic Gates Implement given function using only NAND gates. Design F(A,B,C) = Σm(2,3,4,5) using 2 NAND ICs. Lab 5: Magnitude Comparators Design and implement 3-bit equality checker and 2-bit greater-than comparator. Lab 6: Study of Adder/Subtractor and Up/Down Counter Use CD4008 and XOR IC for 4-bit adder/subtractor. Study counter transitions using 4029 IC. Lab 7: Familiarization with Multiplexer and Decoder ICs Use 8:1 MUX to implement full adder sum function and given logic function. Verify 3-to-8 decoder (79LS138). Lab 8: Design of Counters and Flip-Flop Conversion Verify D and JK flip-flops. Construct SR from D flip-flop. Design a 3-bit JK counter from 000 to 111.
