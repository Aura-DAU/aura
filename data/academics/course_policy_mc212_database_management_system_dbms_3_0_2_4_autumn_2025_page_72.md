## Course Structure

| Lectures | Topic |
|---|---|
| 2 | Course Overview: Basic Definitions, Data Storage, Queries, Transaction Management |
| 4 | Relational Model: Introduction, Integrity Constraints, Logical Database Design |
| 4 | Query Language: SQL |
| 4 | Requirements Collection and Analysis Data Models: E‐R Model, Conceptual Design |
| 5 | Database Design & Tuning: Functional Dependency, Normal Forms, Decomposition, Normalization, Schema Refinement |
| 4 | Data Storage: Physical Storage, Hierarchy, Data Storage Structures Indexing Techniques |
| 4 | Query Processing and Optimization: Query Cost, Evaluation Plans, Materialized Views |
| 4 | Transaction Management: ACID properties, Transactions as SQL Statements Concurrency Control: Lock based, Time stamp based, Validation based, Deadlock detection and handling, Multiversion, Multigranularity |
| 4 | Distributed and Parallel Databases: Data Storage and Query Processing |
| 4 | Modern Databases: NoSQL Databases, Columnar Storage |
