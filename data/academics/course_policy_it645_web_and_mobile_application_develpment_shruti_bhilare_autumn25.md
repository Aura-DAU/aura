## Detailed Course Content

The basic building blocks of webpages: HTML 5, CSS3 and Javascript . Additionally, front-end framework for creating dynamic web pages ( ReactJS ) and the NodeJS and MongoDB backend comprising the MERN stack and React Native. Detailed course content is listed below.
