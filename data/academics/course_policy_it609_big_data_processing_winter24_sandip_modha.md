# IT609 Big Data Processing Winter24 - Sandip Modha

**Last Modified:** 2023-12-22

## Overview

This document presents the course syllabus, policy guidelines, and lecture breakdown for IT609 Big Data Processing Winter24 - Sandip Modha.

## Main Content

Course Title: Big Data Processing  (BDP) 
 
Course Code : IT609 
Credit Structure (L-T-P-Cr ): (2-0-2-3) [two hrs lecture and two hrs Lab per week] 
Course Placement:  Core course for Sem II students of MSc (Data Science) 
Prerequisites (if any)/desired skill set: Understanding of Linear algebra, basic probability, Database 
system, basic algorithms and data structures, Python programming and Linux. 
Course objective : The recent advancement in ICT technologies and social media has triggered 
exponential growth in data. As per Wikipedia, Big data refers to data sets that are too large or complex 
to be dealt with by traditional data-processing application software. This course is planned to cover 
concepts and standard tools used to process and analyze Big Data.  We will study the modern 
distributed computing platform (Hadoop, SPARK). We will cover the algorithms to extract the model and 
Information from the large dataset. We will study the machine learning algorithm on Spark 
Course content [36 (~one hour) Lecture sessions]: 
Module 1:  Introduction Big Data: Characteristics, types of Big data, Big data: Case studies  
Distributed Computing at Glance 
Module 2:  Hadoop FrameWork: Hadoop Ecosystem, Hadoop File System, YARN, MapReduce, Pig, Hive, 
Spark, Mahout, HBase, Solr, Lucene, Zookeeper, Oozie 
Module 3:  MapReduce: Introduction, Architecture, The Map Tasks, Grouping by Key, The Reduce Tasks, 
Combiners, Details of MapReduce Execution 
Module 4:  SPARK: Architecture, RDD, SPARK DataFrame, SPARK SQL, Spark GraphX 
 
Module 5 :  Streaming Algorithms. Stream data model, Sampling data in a stream, Filtering a streams, 
The Bloom Filter, Counting distinct elements in a stream. 
Module 6 :  Link Analysis.  PageRank, PageRank Iteration Using MapReduce 
Module 7 : Frequent Itemsets: Definition, Algorithm of Park, Chen, and Yu, the Multistage Algorithm, the 
Multihash Algorithm,the SON Algorithm 
 
Module 8  : Machine Learning with Spark: Regression, classifications, and clustering problems in spark. 
Module 9 : Recommender System: A Model for Recommendation Systems, Content-based 
Recommendation, Collaborative Filtering 
 
Course Outcome:  Ability to create reliable and scalable distributed system with Apache Hadoop and 
SPARK. Ability to design and implement  the real time data processing system that work on streaming 
data.
