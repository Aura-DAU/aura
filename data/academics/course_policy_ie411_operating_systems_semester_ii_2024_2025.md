## Course Description
The course explains the evolution of computer operating systems from a simple program loader to a complete resource manager of a computing platform. We look at the structure of a modern operating system, and the design of its components. Important components like processes, memory, I/O, and file systems are studied in detail. We also study the implementation of these constructs in the context of a basic Unix-like operating systems.

In the laboratory, experiments/assignments cover: system programming in Unix-like OS, multithreading, and concurrency control. At the end of the course, students are expected to have an in-depth understanding of a modern OS architecture and be able to understand and implement programs using system calls.

## Course Structure

| IE411 Unit | Topic | No. of Lectures |
|---|---|---|
| 1 | Overview (Review of a Computer System, Evolution of Operating System, Components of a modern OS, Operating System Architecture) | 5 |
| 2 | Process Control (Need for a process abstraction, Process and Scheduling, Process synchronization, Inter process communication, Resource management among processes) | 8 |
| 3 | Memory Subsystem (Storage hierarchy, Running programs on a system, Virtual memory, Secondary storage mechanisms) | 8 |
| 4 | File Subsystem (Concepts, User view of information/data, Filesystem constructs and implementation, Unix-like File systems) | 8 |
| 5 | I/O Handling (I/O control, device management, Device driver and virtual device abstraction, Resource protection) | 6 |
| 6 | Additional Topics (Distributed OS, Real Time and Multimedia OS, Computer Networks and distributed OS, Security) | 5 |
