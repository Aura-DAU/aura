# Course File Format and Availability

## Availability

DAU's public accreditation material says instructors submit a course file before the semester and that course files are shared with students through the Lecture subfolder of the university intranet.

A downloadable blank course-file template was not found on DAU's public website during verification on 4 August 2026. AURA should not present an inferred layout as the official template. Faculty and students seeking the exact current template should use the university intranet or the format issued by the Dean (Academic Programmes) office.

## Publicly Documented Contents

The official Annual Quality Assurance Report states that the prescribed course-file format contains:

- Course abstract
- List of topics to be covered
- Reference books and textbooks
- Assessment and grading policy, including applicable quizzes, in-semester examinations, end-semester examinations, lab assignments, and course projects

DAU's accreditation material also says a course outline documents lectures, readings, assignments, laboratories, assessment policy, and expected learning outcomes aligned with programme educational objectives.

## Source Note

This entry records only the course-file requirements described in public DAU documents. It is not a replacement for the internal blank template.
