# Student Registration Details in UniRP

## Overview

This guide explains how students complete **Semester Registration** through the **UniRP Student Portal** at Dhirubhai Ambani University (DA-IICT). UniRP is the ERP system used for course selection, elective registration, and final submission.

## Login Details

| Field | Details |
|---|---|
| Username | Your Student ID |
| Password | Use "Forgot Password" to set a new password on first login |
| Login Portal | [https://login.dau.ac.in](https://login.dau.ac.in) |

## Registration Status Meanings

| Status | Meaning |
|---|---|
| **Closed** | Registration not open yet, or the window has ended |
| **Pending** | Registration window is open but you have not completed all steps |
| **Successfully Completed** | All steps completed and final submission confirmed |

## Step-by-Step Registration Process

| Step | Action |
|---|---|
| 1 | Log in to [https://login.dau.ac.in](https://login.dau.ac.in) with your Student ID and password |
| 2 | Navigate to **Semester Registration** from the Student Portal |
| 3 | Click the registration button (shows current status) |
| 4 | Confirm the warning — you must complete all steps once started |
| 5 | Review and confirm **Core (Mandatory) Courses** — auto-assigned, cannot be changed |
| 6 | Select **Specialization Courses** (if applicable) — choose all subjects within a slot and set priorities |
| 7 | Select **Program Elective Courses** — choose preferred slot(s), select all subjects within each slot, assign preferences |
| 8 | Optionally select an **Audit Course** from any slot skipped in the previous step |
| 9 | Set **Slot Preferences** for all selected elective slots |
| 10 | Review **Student Requirements** and enter any required inputs per subject category |
| 11 | Review the full list of selected Core, Elective, and Audit subjects |
| 12 | Agree to the declaration and click **FINAL SUBMIT** |

## Editing After Confirmation

- You can edit any step before the final submit by clicking **EDIT** on that step.
- Editing a step resets all subsequent steps — you must redo them.

## Important Warnings

- Once you click FINAL SUBMIT, registration is confirmed.
- Check all selections thoroughly before submitting.
- If you skipped any elective slot, its subjects appear as Audit Course options.
- The student module is under development — only **Student Registration** and **Fees** links are currently active.
