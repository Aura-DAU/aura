## Course Description

Cloud computing systems today, both open source or proprietary are built using a common set of core techniques, algorithms, and design philosophies, all of which are centered around distributed systems. This course will teach the fundamental concepts of how and why Cloud systems work, as well as Cloud technologies that manifest these concepts, such as from Amazon AWS, Microsoft Azure, and OpenStack. ### Lecture Outline

- : Topics Number of lectures I Introduction to Cloud Computing: Introduction, 6 Historical developments, Building Cloud Computing Environments, Operating systems and networks fundamentals II Cloud Computing Architecture: Introduction, 6 Fundamental concepts and models, Cloud Characteristics, Cloud Delivery models, Cloud Deployment models, Economics of the cloud. III Virtualization: Introduction, Characteristics of 8 virtualized environments, Taxonomy of virtualization techniques, Hypervisor, Containers, Dockers, Pros and cons of virtualization, Technology examples. Cloud Architecture.

- IV Principles of Distributed Systems: 4 Elements of distributed systems, Technologies for distributed Computing, consistency and replication. V Service Models in Cloud Computing: 6 Infrastructure as a Service (IaaS), Platform as a Service (PaaS), Software as a Service(Saas) and Metal as a Service (MaaS) VI Real World Cloud Computing Technologies: 6 Introduction to OpenStack, Kubernetes AWS, and Microsoft Azure. VII Guest lectures and demos from Industry experts 5-6.

### Lab Outline:

- Lab 1: Fundamentals of Networking Socket programming Lab 2: 1ntroduction to AWS: The first lab in the series walks the students through the installation and configuration of Virtual Machines on AWS Manager Lab 2: VPC Configuration This lab introduces the concept of virtual private clouds and their installation on AWS Lab3: AWS S3 This lab introduces the concept of Amazon S3.

- Students will gain knowledge on how to Store and manage data by creating S3 buckets, Protecting data using features like versioning, Hosting a static website directly from an S3 bucket, and Automate storage management Lab 4: EC2 Instances This lab introduces how to create EC2 instances and mount an S3 bucket on it to experience how cloud storage and compute can work together seamlessly.

- Lab 5: AWS SageMaker In this lab, students are introduced to a tool for training and deploying ML models. Lab 6: Kubernetes This lab introduces containers and automatic orchestration principles using Kubernetes Lab 7: This lab introduces the concepts of serverless computing and implement a simple AWS Lambda function using the AWS Management Console. The lab also introduces AWS CloudWatch for observing and debugging serverless applications.
