Aims and Objectives:

Cloud computing systems today, both open source or proprietary are built using a common set of core
techniques, algorithms, and design philosophies, all of which are centered around distributed systems.
This course will teach the fundamental concepts of how and why Cloud systems work, as well as Cloud
technologies that manifest these concepts, such as from Amazon AWS, Microsoft Azure, and OpenStack.
Students will learn concepts like virtualization, containers, orchestration and performance analysis at
scale. The hands on component of the course is provided through multiple labs focussing on providing the
necessary practical experience of building and deploying applications on cloud infrastructure. For
example, this will include learning, installing and deploying a web application on Kubernetes platform.
The associated laboratory component is designed to expose students to the various aspects of cloud
computing.

Course outcomes:

At the end of the course, students are expected to:
1. Understand explain virtualization and its role in cloud/elastic computing.
2. Characterize the distinctions between Infrastructure, Platform and Software as a Service (IaaS,
PaaS, SaaS) abstractions, and Public and Private Clouds, and analyze their advantages and
disadvantages
3. Program basic distributed algorithms to understand their significance in cloud computing
4. Able to create and deploy simple applications on the cloud

Lab Outline:


| Lab 1: Fundamentals of Networking | Socket programming |
|---|---|
| Lab 2: 1ntroduction to AWS: | The first lab in the series walks the students through the installation and configuration of Virtual Machines on AWS Manager |
| Lab 2: VPC Configuration | This lab introduces the concept of virtual private clouds and their installation on AWS |
| Lab3: AWS S3 | This lab introduces the concept of Amazon S3. Students will gain knowledge on how to Store and manage data by creating S3 buckets, Protecting data using features like versioning, Hosting a static website directly from an S3 bucket, and Automate storage management |
| Lab 4: EC2 Instances | This lab introduces how to create EC2 instances and mount an S3 bucket on it to experience how cloud storage and compute can work together seamlessly. |
| Lab 5: AWS SageMaker | In this lab, students are introduced to a tool for training and deploying ML models. |
| Lab 6: Kubernetes | This lab introduces containers and automatic orchestration principles using Kubernetes |
| Lab 7: | This lab introduces the concepts of serverless computing and implement a simple AWS Lambda function using the AWS Management Console. The lab also introduces AWS CloudWatch for observing and debugging serverless applications. |
