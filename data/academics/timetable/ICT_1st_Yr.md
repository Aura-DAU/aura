# Timetable — B.Tech ICT — 1st Year (Autumn 2026-27)

Source: derived from the official DAU Autumn 2026-27 combined lecture timetable, filtered by course code.

## Important context

DA-IICT's 1st-year curriculum runs on a shared "Common Curriculum Framework" — Intro to ICT, Calculus, Programming, Basic Electronic Circuits, Language & Literature are the same Institute Core courses for every branch, split into four room-capacity sections (A–D) that mix students across branches. The only branch-specific signal in the raw timetable data is a set of six parallel "PC1" (Program Core 1) sessions, all run at the same three time slots (Mon 9, Wed 8, Thu 10), each in a different room:

- PC1 (ICT) — Rm CEP-106, faculty RM
- PC1 (MNC) — Rm CEP-204, faculty VS
- PC1 (EVD) — Rm CEP-205, faculty AR
- PC1 (CS-AI) — Rm CEP-103, faculty SCN
- PC1 (unlabeled #1) — Rm CEP-108, faculty SB2
- PC1 (unlabeled #2) — Rm CEP-206, faculty AB

Note: this is the plain-ICT PC1 group. Per your own course-structure sheets, ICT and ICT-CS students are on the *same* curriculum through Semester 3 — ICT-CS only diverges starting Semester 4 with an "Honors" substitution. So it's likely (but not confirmed in the source) that ICT and ICT-CS 1st-years actually sit together in this PC1 (ICT) session, and the "ICT-CS" file below is really a best-effort split, not a data-confirmed one.
