## In-Depth Profile / Student Guide

### Research Identity
His academic identity is very systems + software + performance engineering (Embedded Systems, Computer Networks, High Performance Computing, Machine Learning applied to systems). His research is not generic ML - it is systems-level performance modeling.

### Core Research Areas
1. **Performance Prediction (Core Area):** ML models predicting real hardware performance using simulation data.
2. **Transfer Learning in Systems:** Using ML models trained on simulated systems and applying them to real systems, Scaling performance models across architectures.
3. **HPC / Benchmark Analysis:** Evaluating workloads across different system architectures.

### Research Style
He tries to answer: "If we simulate a computer system, can we accurately predict how real hardware will behave?"
