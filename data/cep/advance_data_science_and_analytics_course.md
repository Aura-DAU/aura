## 1. Course Objective

Equip participants with essential skills in Python programming for data analysis, covering data manipulation with NumPy and Pandas, statistical analysis and feature engineering, data visualization using Matplotlib and Seaborn, introduction to machine learning algorithms (regression, SVM), model evaluation techniques, and data storytelling with Tableau.

## 2. Expected Outcome

Participants will gain a comprehensive understanding of Python for data analysis, machine learning techniques, and Tableau-based visualization, and will be able to manipulate data, apply ML algorithms, and build interactive dashboards.

## 4. Mentoring Program (7 Weeks)

Weekly sessions cover: Python setup, data structures, functions/modules, NumPy/Pandas, file handling, data sanitization, feature engineering, statistical analysis, visualization (Matplotlib/Seaborn), intro to ML, regression, logistic regression, feature selection, SVM, model evaluation/hyperparameter tuning, Tableau visualization and data storytelling, and a capstone project (kickoff, feature engineering, model building, evaluation, report visualization).
