# Workshop on "Data Analysis using Python" (15–19 July 2024)

Workshop under the Anchor Institute Program (AIP).

## Overview

- **Dates:** 15.07.2024 to 19.07.2024
- **Venue:** DA-IICT, Gandhinagar
- **Course Duration:** 40 hours (20 hours theory + 20 hours lab)
- **Target Audience:** Professionals, Faculties, Ph.D. Scholars, PG and Final year UG Students
- **Course Fee:** ₹5,000, fully refundable for Gujarat-state participants (non-refundable for candidates from other states)
- **Accommodation:** Complimentary accommodation, tea/coffee/snacks throughout the workshop
- **Refund Policy:** Maintain 75% minimum attendance
- **Certificate:** Participation certificate for ≥75% attendance
- **Registration Deadline:** 04th July 2024

## 1. Course Overview

Covers machine learning and the latest developments in data science, applicable across engineering disciplines — artificial neural networks, deep learning, and statistical/ML approaches to data analytics.

## 2. Course Objectives

- Foundational understanding of Python scripting
- Design and implement real-world ML applications
- Career development through innovative, independent learning
- Project work on real-life problems

## 3. Expected Outcome

Participants gain a deep understanding of ML principles and their applications, Python scripting skills, and project-based problem-solving experience in data analytics.
