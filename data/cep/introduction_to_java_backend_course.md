# Introduction to Java Backend

Course under the Anchor Institute Program (AIP), 2022-23.

## Overview

- **Sponsor:** Centre for Continuing Education (CED office, Govt. of Gujarat)
- **Conducted by:** DA-IICT in collaboration with Rishabh Software Pvt Ltd
- **Target Audience:** Faculties from Computer Science & Engineering departments at engineering colleges in Gujarat
- **Start Date/Time:** 31st March 2023, 10:30 AM
- **Venue:** Online (offline examinations at DA-IICT campus, Gandhinagar)
- **Cost:** Free of charge
- **Industry Partner:** Rishabh Software Pvt. Ltd. (instructors are production-experienced Java backend developers/architects)

## Brief Course Description

Deep understanding and hands-on training on Java backend technologies: OOP concepts, Java essentials, streams and files, generics, servlets, SOAP/REST API, Spring MVC, Spring Boot, and Hibernate.

## Outcomes

Trains faculty in advanced Java backend development skills to pass on to students. Participants receive a certificate of participation and an optional credit certificate with grades.

## Lecture Schedule

| # | Topic | Hours |
|---|---|---|
| 1 | Introduction: Java history, bytecode, JVM, compilers, JDKs, IDEs | 1 |
| 2 | Core Java: Java Essentials (data types, operators, loops, exceptions, packaging) | 1.5 |
| 3 | Core Java: OOP (classes, interfaces, inheritance, polymorphism, access specifiers) | 1 |
| 4 | Core Java: I/O (byte/character/buffered/data/object streams, file operations) | 3 |
| 5 | Core Java: Generics; Features of Java 8+ (lambdas, functional interfaces, streams, optionals) | 5 |
| 6 | Web Programming Basics: JSP, Servlets, SOAP/REST | 3.5 |
| 7 | Web Programming: Spring MVC (IoC, DI, Transaction Mgmt, Spring Data JPA) | 5 |
| 8 | Web Programming: Spring Boot (annotations, starters, actuator, properties, DevOps) | 10 |
| 9 | Persistence: Hibernate (architecture, mapping, CRUD, inheritance, HQL/Criteria) + case-study project | 10 |
