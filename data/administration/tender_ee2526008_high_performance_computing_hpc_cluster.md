# Tender EE2526008 — High Performance Computing (HPC) Cluster

## Overview

Tender for Supply, Installation and Commissioning of a High-Performance Computing (HPC) Cluster for DA-IICT Society, Gandhinagar. Issued by DA-IICT Society (Registration No. F/818/Gandhinagar, dated 29 October 2001).

## Main Content

- **Submission deadline:** 22 December 2025, before 1:00 PM
- **Tender Fee:** ₹10,000 (non-refundable), via NEFT/RTGS to DA-IICT Society, ICICI Bank Gandhinagar (A/c: 016501012802, IFSC: ICIC0000165)
- **Warranty:** 3-year comprehensive on-site warranty (all HW/SW/firmware); optional 2-year extension quote
- **Uptime penalty:** 0.10% of order value if minimum uptime guarantee not met
- **Advance payment:** Up to 50% of order value against bank guarantee
- **Liquidated damages:** 0.1% of order value for delivery/installation delays

### Key Technical Specifications (Annexure 3)
- **Master Node (2U server, Qty 1):** AMD EPYC 9355P 32-core processor, 192GB RAM, 8x 20TB SAS HDD, 2x 960GB NVMe SSD, Mellanox ConnectX-6 HDR100/100GbE adapter
- **GPU Compute Node (3U, Qty 1):** 2x AMD EPYC 9645 96-core, 384GB RAM, 2x NVIDIA RTX PRO 6000 Blackwell 96GB GPUs
- **GPU Compute Node #2 (3U, Qty 1):** 2x AMD EPYC 9645 96-core, 2x NVIDIA H200 NVL 141GB GPUs
- **Network Switch:** Netgear XSM4344C, 40x 1G/10GbaseT + 4x 100GbE ports
- **Infrastructure:** 42U rack, 30kVA (3x3) online UPS with 36x 65AH SMF batteries, 3x 3TR precision cooling units (2+1 redundancy), rackmount KVM console
- OEM options: DELL/Tyron/Lenovo/Asus/HP
- Contact: procurement@dau.ac.in or research_officer@dau.ac.in

## Important Information

- **Tender No.:** EE2526008
- **Issuing body:** DA-IICT Society
- **Warranty requirement:** OEM or authorized System Integrator support with a Single Point of Contact (SPOC)
